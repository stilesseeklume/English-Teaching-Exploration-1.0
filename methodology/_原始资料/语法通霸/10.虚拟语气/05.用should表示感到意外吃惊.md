# 第5讲 用should表示"感到意外、吃惊"

## 概述
本讲讲解情态动词should表示说话人对某事不能理解，感到意外、惊异等意思的用法。这种用法中的should常译为"竟会"，用于表达惊讶、不可思议的情绪，常见于疑问句、感叹句及"It is surprising/strange that..."等句型中。

## 详细内容

### 考点 1. should表示"意外、吃惊"的基本用法
should可用来表示说话人对某事不能理解，感到意外、惊异等意思，常译为"竟会"。

#### A. 疑问词how, why等连用，有"竟、会"之意
**示例**:
- Why should you stand there like a fool? (你怎么像傻子一样站在那里?)
- How should I know? Has it anything to do with me? (我怎么知道?这和我有什么关系?)
- I don't know why you should have told him that much. (我不明白你为什么跟他说那么多。)

**注意**: "should + have done"表示已发生的情况。

#### B. 在"It's surprising/strange/a pity..."以及"I'm surprised/sorry..."等句型中，当"竟然会"讲
**示例**:
- It's surprising that he should be so foolish. (他竟然这么愚蠢，真是令人吃惊!)
- It's strange that such a thing should happen in your school. (竟然会在你们学校发生这种事，真是奇怪。)

### 考点2. 对现在的情况表示吃惊
对现在情况表示吃惊时，用"should + 动词原形"。

**示例**:
- It is strange that such a thing should happen in your school. (竟然会在你们学校发生这种事，真是奇怪。)
- You can't imagine that a well-behaved gentleman should be so rude to a lady. (你无法想象一个举止得体的绅士竟然会对一位女士如此粗鲁。)

### 考点3. 对过去的情况表示吃惊
对过去情况表示吃惊时，用"should + have + done"。

**示例**:
- It's wonderful that you should have achieved so much in these years. (这些年你竟然取得了这么多成就，真是太好了。)
- It's strange that he should have taken the books without the owner's permission. (他竟然未经主人允许就拿走了这些书，真是奇怪。)
- It is surprising that he should have been so foolish. (他竟然这么愚蠢，真是令人吃惊。)

### 考点4. should与其他情态动词的对比
在表示"意外、吃惊"的用法中，should有特定的语义色彩，与其他情态动词有所不同：

- **would**: 表示意愿或过去习惯
- **could**: 表示可能性或能力
- **might**: 表示较小的可能性
- **should**: 专门表示惊讶、意外

**示例对比**:
- It is strange that he should have taken the books. (惊讶：他竟然拿了书)
- It is possible that he might have taken the books. (可能性：他可能拿了书)
- It is likely that he would have taken the books. (可能性较大：他很可能拿了书)

### 考点5. 常见句型结构

#### 结构1: It is + 形容词 + that + should + 动词原形/have done
**形容词**: surprising, strange, wonderful, amazing, incredible, odd, curious等

**示例**:
- It is surprising that the exams should be so difficult. (考试竟然这么难，真是令人吃惊。)
- It is wonderful that the Chinese people should have made so much progress these years. (中国人民这些年竟然取得了这么大进步，真是太好了。)

#### 结构2: 疑问词 + should + 主语 + 动词
**示例**:
- Why should I believe you? (我为什么要相信你?)
- How should he know the answer? (他怎么会知道答案?)

#### 结构3: I'm surprised/sorry + that + should + 动词
**示例**:
- I'm surprised that you should say that. (你竟然这么说，我很惊讶。)
- I'm sorry that things should have turned out this way. (事情竟然变成这样，我很遗憾。)

## 核心要点总结

1. **语义核心**: should表示"意外、吃惊"，译为"竟会"
2. **时态搭配**:
   - 对现在吃惊: should + 动词原形
   - 对过去吃惊: should + have done
3. **常见句型**:
   - It is + 形容词 + that...
   - 疑问词 + should...
   - I'm surprised/sorry that...
4. **形容词选择**: surprising, strange, wonderful, amazing等表达惊讶情绪的形容词
5. **与事实关系**: 表示说话人对已发生或正在发生的事感到意外，不一定是与事实相反

## 学习建议

1. **句型记忆**: 熟记"It is strange that...should..."等固定句型
2. **时态判断**: 根据时间状语判断用should do还是should have done
3. **语义辨析**: 区分should表示"应该"与表示"惊讶"的不同用法
4. **真题应用**: 通过高考真题掌握考点考查方式

## 易错点提示

1. **不要与虚拟语气混淆**: 此处的should表示惊讶，不是虚拟语气中的"应该"
2. **不要省略should**: 在表示惊讶的句型中，should一般不能省略
3. **注意时态一致**: 主句为现在时，从句根据实际情况选择时态
4. **区分形容词**: 只有表达惊讶、意外等情绪的形容词才适用此结构
