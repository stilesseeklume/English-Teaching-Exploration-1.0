# 🗣️ 语言能力要求

> **定义**：语言能力指在社会情境中，以听、说、读、看、写等方式理解和表达意义的能力，以及在学习和使用语言的过程中形成的语言意识和语感。

## 📖 基本定位

### 在核心素养体系中的角色
- **地位**：英语语言能力构成英语学科核心素养的**基础要素**
- **关系**：英语语言能力的提高蕴含文化意识、思维品质和学习能力的提升
- **作用**：有助于学生拓展国际视野和思维方式，开展跨文化交流

### 能力构成维度
1. **理解能力**：听、读、看等方式理解意义
2. **表达能力**：说、写等方式表达意义
3. **语言意识**：对语言系统的认识和敏感性
4. **语感培养**：对语言运用的直觉把握能力

---

## 🎯 语言能力目标

### 总体目标
具有一定的语言意识和英语语感，在常见的具体语境中整合性地运用已有语言知识，理解口头和书面语篇所表达的意义，识别其恰当表意所采用的手段，有效地使用口语和书面语表达意义和进行人际交流。

### 具体能力表现
1. **语境适应能力**：在常见具体语境中整合运用语言知识
2. **语篇理解能力**：理解口头和书面语篇的意义
3. **表达手段识别**：识别语篇恰当表意所采用的手段
4. **人际交流能力**：有效使用口语和书面语进行人际交流

---

## 📊 语言能力水平划分

> 注：详细水平划分参见[[附录1 英语学科核心素养水平划分]]。以下为摘要：

### 水平一（基础水平）
- 能在熟悉语境中理解简单语篇的基本信息
- 能使用简单语言进行基本的人际交流
- 初步形成英语语言意识和基本语感

### 水平二（发展水平）
- 能在常见语境中理解不同类型语篇的主要信息
- 能就熟悉话题进行比较连贯的表达和交流
- 形成一定的语言意识，能识别语言的基本特征

### 水平三（提高水平）
- 能在多种语境中理解复杂语篇的深层含义
- 能就广泛话题进行有效、得体的表达和交流
- 具有较强的语言意识，能分析和评价语言运用

## 🔄 与其他素养的关系

### 语言能力 → 文化意识
- 语言是文化的载体，语言能力的提高促进文化理解
- 跨文化交流需要语言能力作为基础支撑

### 语言能力 → 思维品质
- 语言是思维的工具，语言发展促进思维发展
- 复杂思维活动需要高级语言能力支持

### 语言能力 → 学习能力
- 语言能力是学习其他知识的基础
- 高效学习需要良好的语言理解和表达能力

## 🏫 教学实施建议

### 教学设计原则
1. **情境化原则**：在真实社会情境中发展语言能力
2. **整合性原则**：将听、说、读、看、写有机结合
3. **渐进性原则**：从简单到复杂逐步提升语言水平
4. **应用性原则**：强调语言在实际交流中的应用

### 活动设计示例
- **角色扮演**：在模拟情境中练习语言运用
- **项目学习**：通过完成项目任务发展综合语言能力
- **语篇分析**：分析不同语篇的语言特征和表达手段
- **交流实践**：开展真实或模拟的跨文化交流活动

### 评价建议
1. **多元评价**：结合形成性评价和终结性评价
2. **表现评价**：关注学生在真实任务中的语言表现
3. **发展评价**：关注学生语言能力的发展过程
4. **自我评价**：引导学生反思自己的语言学习进展

## 📚 与教材内容的关联

### 必修教材语言能力要求
- **主题语境**：在教材设定的主题语境中发展语言能力
- **语篇类型**：接触不同类型语篇，发展相应理解能力
- **语言知识**：系统学习语音、词汇、语法、语篇知识
- **技能训练**：通过专项练习提升听、说、读、看、写技能

### 选修教材语言能力延伸
- **拓展话题**：接触更广泛话题，发展专业领域语言能力
- **高阶技能**：培养分析、评价、创造等高阶语言能力
- **个性发展**：满足学生个性化语言能力发展需求
