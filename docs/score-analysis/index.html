Score Analysis

英语学科质量分析，不只是算平均分。

面向教务主任和英语学科组长：看年级整体、班级差异、题型结构、临界学生、进退步和增值性。高考口径默认按卷面 120 分换算 130 分，再加听说 20 分，合成 150 分。

数据导入

支持 CSV/TSV、从 Excel 复制粘贴，也可上传 .xls/.xlsx。第一张表建议用“学生小题分”或“学生题型分”。

真实高考结构：阅读 37.5、七选五 12.5、完形 15、语法填空 15、应用文 15、读后续写 25，卷面共 120；最终分 = 卷面 / 120 × 130 + 听说原始分（20）。没有听说列时，系统会先按卷面折算展示。
