## 第一部分：阅读理解考查什么？

### 1.1 陈康的七项阅读理解能力

根据陈康等在高考评价体系中的界定，阅读理解考查7项能力：

| 编号 | 能力维度 | 对应题型 |
|------|----------|----------|
| 1 | 理解主旨要义 | 主旨大意题 |
| 2 | 理解具体信息 | 细节理解题 |
| 3 | 推断词义 | 词句猜测题 |
| 4 | 判断推理 | 推理判断题 |
| 5 | 理解文章结构/衔接 | 七选五 |
| 6 | 理解作者意图/观点/态度 | 推理判断题（观点态度子类） |
| 7 | 识别文体特征 | 主旨大意题、文章出处题 |

赢在微点的5个专题完全覆盖这7项能力。

### 1.2 高考阅读文章的分类命题特征

赢在微点将高考阅读文章按位置分类：

| 位置 | 文体 | 特征 | 解题策略 |
|------|------|------|----------|
| **A篇** | 应用文 | 信息密集、定位清晰、答案直接 | 题干定位法——关键词快速定位 |
| **B篇** | 人文记叙文/说明文 | 以人为本，问题→解决→感悟 | 关注时间线 + 主题递进 + 特殊点 |
| **C/D篇** | 社科/科普说明文、议论文 | 研究发现 + 数据支撑 + 专家观点 | 抓标志词 + 主题句 + 逻辑推进 |

### 1.3 通用解题原则

1. **出题顺序与行文一致**（题文同序）—— 第1题对应文章前部，第4题对应文章后部
2. **不用读懂每一句话**—— 重点读与题目对应范围内的句子
3. **正确选项 = 原文信息的同义转述**—— 这是所有题型共通的底层逻辑
4. **干扰项有固定套路**—— 张冠李戴、偷梁换柱、推断过度、以偏概全、无中生有、颠倒是非

## 第二部分：五大题型解题方法（赢在微点）

### 题型1：细节理解题 —— 题干定位法（读、圈、寻、比）

**考查能力**：陈康能力2（理解具体信息）

#### 步骤

| 步骤 | 操作 | 详细说明 |
|------|------|----------|
| **读** | 读题干 | 先读题干，不读选项 |
| **圈** | 圈关键词 | 圈出题干中的核心词（人名、地名、时间、专有名词），预判原文可能的同义转述 |
| **寻** | 寻读定位 | 在原文中快速搜索关键词，找到答案范围（通常1-2句） |
| **比** | 比对选项 | 将原文信息与每个选项比对（注意同义转述），选出最佳匹配 |

#### 三种子题型

| 子类型 | 特征 | 解题技巧 |
|--------|------|----------|
| **直接信息理解题** | 原文和选项几乎原词对应 | 定位搜复现，不需分析推理 |
| **综合信息理解题** | 正确选项是原文的同义转述 | 可跨越多个信息点，需概括归纳 |
| **数据计算题** | 涉及时间、数量、价格的计算 | 找到计算背后的隐含信息 |

#### A篇三种结构特点

| 结构 | 特征 | 解题策略 |
|------|------|----------|
| 大标题 + 小标题 | 标题揭示段落主旨 | 根据标题快速锁定对应段落 |
| 图片/图表 + 文本 | 多模态信息 | 注意表格行列对应的主题 |
| 平行段落 | 信息同序排列 | 题干关键词与段落顺序对应 |

### 题型2：推理判断题 —— 4类标志 + 6种子题型

**考查能力**：陈康能力4（判断推理）+ 能力6（理解作者意图/观点/态度）

#### 通用方法：定、析、比、推

1. **定**：根据题干定位信息范围
2. **析**：分析隐含的逻辑关系
3. **比**：对比选项间的差异
4. **推**：推出言外之意（推断要有据，不可推断过度）

#### 六种子题型的解题技巧

| 子类型 | 标志词 | 解题技巧 |
|--------|--------|----------|
| **隐含推断** | infer, indicate, imply, suggest, conclude | 找到原文依据 → 基于依据合理推断 → 不推断过度 |
| **观点态度** | attitude, think, feel, believe, opinion | 找褒贬形容词/副词/动词 → 判断正面/负面/中性/客观 |
| **写作意图** | purpose, intend to, try to show, by mentioning | 先定主旨 → 分辨文体 → 推断意图（inform/persuade/entertain/warn） |
| **文章出处** | where taken from, what type, target audience | 看文体特征 + 用词 + 主题 → 判断来源（newspaper/magazine/website/textbook） |
| **人物/事物特征** | which best describes, what words describe | 归纳人物的行为/语言/成就 → 提炼品质/特征 |
| **预测后文** | what might be talked about next | 锁定最后一段最后一句 → 做逻辑延伸 |

#### 研究发现类说明文的四类标志

这是C/D篇最常见的文体，赢在微点总结了四条定位规则：

| 标志 | 位置 | 作用 |
|------|------|------|
| **主题句 + 支撑句** | 段首或转折词后 | 找段落主旨 → 常用于段落大意题 |
| **强转折词后** | but, however, actually 之后 | 真正的观点/结论往往在这里 → 常用于写作意图题 |
| **举例内容** | for example, such as 之后 | 例子证明前面的主题句 → 答案往前找主题句 |
| **专家建议** | 文章结尾 | 指向潜在应用/发展方向 → 常用于预测后文 |

#### 常见态度词速查表

| 态度 | 词汇 |
|------|------|
| 正面 | positive, supportive, approving, optimistic, favorable, admiring |
| 负面 | negative, critical, disapproving, pessimistic, doubtful, skeptical |
| 客观 | objective, neutral, factual, balanced |
| 担忧 | concerned, worried, cautious |
| 讽刺 | ironic, sarcastic |

### 题型3：主旨大意题 —— 体裁 + 串线法

**考查能力**：陈康能力1（理解主旨要义）+ 能力7（识别文体特征）

#### 通用方法：体裁 + 串线

1. **判断体裁**：说明文 or 议论文 → 不同的阅读策略
2. **串线**：将每段的大意串联起来 = 全文主旨

#### 三种子题型

| 子类型 | 常见设问 | 解题方法 |
|--------|----------|----------|
| **段落大意** | What is paragraph X mainly about? | 找段首主题句（或转折词后的句子）→ 如果段首没有，自己归纳 |
| **全文大意** | What is the text mainly about? | 体裁判断 + 串线法（串联每段大意） |
| **最佳标题** | Which can be the best title? | 标题 = 主旨的精炼版，要概括全文而非局部 |

#### 议论文常见论证模式

```
现象/问题 → 原因/案例支撑 → 解决方案 → 建议/反思结论
```

知道这个模式后，读C/D篇议论文时心里就有一个"地图"——你知道作者接下来大概会说什么。

#### C/D篇三大结构特征

| 特征 | 标志 | 常设题型 |
|------|------|----------|
| 主题句明确 | 段首第一句，或让步状语从句后的主句，或转折词后 | 段落大意、写作意图 |
| 逻辑词明显 | however, instead, nevertheless, moreover, therefore | 推理判断、推断目的 |
| 结尾行动倡议 | 尾段建议/呼吁 | 写作意图、预测后文 |

### 题型4：词句猜测题 —— 4角度 + 就近原则

**考查能力**：陈康能力3（推断词义）

#### 三种子题型

| 子类型 | 方法 |
|--------|------|
| **单词/短语猜测** | 4角度快猜词 |
| **代词指代** | 就近原则 + 一致原则 |
| **句意猜测** | 意义吻合法 |

#### 四角度猜词法

| 角度 | 操作 | 示例 |
|------|------|------|
| **1. 语境推测** | 用周围的句子和段落大意判断词义 | 上下文对"某种人"的行为描述 → 推出此词的性质 |
| **2. 逻辑关系 + 语境** | 利用句间逻辑（对比、因果、递进） | "but X"→X与前面的内容相反 |
| **3. 语法关系 + 语境** | 利用冒号（解释）、破折号、同位语 | 冒号后 = 对前面的定义/解释 |
| **4. 构词法** | 前缀 + 词根 + 后缀 | micro-（微）+ plastic（塑料）= 微塑料 |

#### 代词指代：就近原则 + 一致原则

| 代词 | 通常指代 |
|------|----------|
| it | 前文的单数/不可数名词 |
| they | 前文的复数名词 |
| this | 前文的动作/方法（多为动词性内容） |
| that | 前文的物/事（多为名词性内容） |
| one/ones | 同类的泛指 |
| those | 特指的复数名词 |

### 题型5：七选五 —— 四步法 + 8类逻辑关系 + 5技巧

**考查能力**：陈康能力5（理解文章结构/衔接）

#### 四步法

| 步骤 | 操作 |
|------|------|
| **第一步：读** | 速浏览，定主旨——快速扫读首段、每段首句、尾段 |
| **第二步：析** | 析选项，提核心——读选项，标记逻辑标志词和代词，判断每个选项可能的位置（段首/段中/段尾） |
| **第三步：寻** | 看位置，定答案——先做段首段尾（容易），再做段中（难） |
| **第四步：代** | 代所选，看通顺——代入后通读全文，检查连贯性 |

#### 8类逻辑关系

| 关系类型 | 标志词 | 运用 |
|----------|--------|------|
| 并列 | and, or, also, as well as, firstly, secondly | 前后意义同向 |
| 递进 | moreover, furthermore, besides, even, what's more | 后句更进一层 |
| 顺承 | then, afterwards, finally, eventually, meanwhile | 时间/逻辑顺序 |
| 因果 | because, since, therefore, thus, as a result | 前后因果关系 |
| 解释 | that is, namely, in other words, to be specific | 后句解释前句 |
| 举例 | for example, for instance, such as, like | 后句证明前句 |
| 转折 | but, however, yet, instead, on the contrary | 前后意义反向 |
| 总结 | in short, to sum up, in conclusion | 段尾总结前文 |

#### 5技巧

| 技巧 | 方法 | 核心原则 |
|------|------|----------|
| **词汇衔接** | 原词复现 / 近义词复现 / 同源词复现 / 反义词复现 / 同范畴词汇共现 | 正确选项的关键词与前后句的关键词重复或呼应 |
| **代词指代** | 找代词的所指（向前找就近的内容） | 人称、数、格一致 |
| **相似句式** | 看平行结构、问句答句、祈使句 | 段首句的形式通常一致；问句后面应有答句 |
| **褒贬一致** | 正面配正面，负面配负面；正负之间必有转折 | 情感色彩不能突变（除非有转折词） |
| **标点符号** | 逗号（从句）、问号（问答） | 标点是小技巧但往往很准 |

- 干扰项明显加强
- 文章地道表达明显增多
- 显性逻辑连接词减少，隐含逻辑关系增多

## 第三部分：唐邦顺的文本解读深度

### 3.1 绝对化用词的内涵

唐邦顺在解读人教版课文 *Virtual Choir* 时，注意到作者的绝对化用词：

> anyone, anywhere, all, even

这些词不是随意使用的——它们传达的是"虚拟合唱团打破了时空限制，彻底改变了音乐创作方式"的核心信息。

**教学指令**：当你在文章中发现绝对化用词（anyone, anywhere, all, never, always, every, only, even），问自己——作者为什么使用这些词？它们在强调什么？

### 3.2 数字暗含的意义

唐邦顺以 *Virtual Choir* 和 *The Night the Earth Didn't Sleep* 为例分析数字：

**Virtual Choir 中的数字**：
- 185 singers from 12 countries（第一个虚拟合唱团的规模）
- 2,292 young people from 80 countries（第二个的规模）
- 数字的递进 → 说明虚拟合唱团的迅速发展

**唐山大地震课文中的数字**：
- Eleven kilometres below the city
- damage more than 150 kilometres away
- one third of the whole nation felt it
- eight kilometres long and 30 metres wide（裂缝）
- 75 percent of factories, 90 percent of homes, all hospitals
- more than 400,000 dead or injured

**数字的功能**：作者大量使用数字是为了 emphasize the scale and severity，让抽象的描述变得具体、生动。

**教学指令**：当文章中出现大量数字时，停下来思考——这些数字在传达什么信息？为什么作者选择用数字而不是模糊描述？

### 3.3 与高考阅读的关联

2024-2025年的高考阅读越来越重视这种"深度解读"能力。八省联考的阅读理解题中，直接考查了"作者为什么使用这些数字"这类问题。

这和我们的三层导问框架中的第三层（语言与写作技巧）完全对应。

## 第四部分：三层导问框架在阅读教学中的应用

将项目已有的三层导问结构适配为阅读理解教学：

### 第一层：文体与写作目的（入篇）

**导问**：
- 这篇文章是什么文体？（应用文 / 记叙文 / 说明文 / 议论文）
- 你从哪里判断出来的？（标题、结构、语言特征）
- 作者的写作目的是什么？（inform / persuade / entertain / warn）
- 目标读者是谁？

**对应题型**：主旨大意、文章出处、写作意图

### 第二层：内容与结构（读篇）

**导问**：
- 每段在说什么？（不要问"P1讲了什么"，要问具体问题）
- 段落之间是什么逻辑关系？（因果 / 转折 / 递进 / 并列 / 解释）
- 作者是按什么顺序组织信息的？（时间 / 空间 / 逻辑 / 问题-解决方案）
- 有哪些关键词贯穿全文？（主题词追踪）

**对应题型**：细节理解、段落大意、七选五

### 第三层：语言与写作技巧（析篇）

**导问**：
- 作者在什么位置使用什么写作手法？（比喻 / 举例 / 对比 / 引用 / 数据）
- 作者为什么用这些数字/绝对化用语？（唐邦顺的深度解读方法）
- 段落内的逻辑是什么？段落间的逻辑是什么？
- 值得学习的表达有哪些？

**对应题型**：推理判断、观点态度、词句猜测

## 第五部分：教学应用

### 5.1 课堂讲题模式

对于每道阅读理解题，按以下模式引导学生：

```
1. 导问（不直接展示答案）
   → 题干关键词是什么？
   → 定位到文中哪里？
   → 原文信息是什么？

2. 分析（引导学生找依据）
   → 正确选项为什么对？（与原文的同义转述关系）
   → 干扰项为什么错？（张冠李戴 / 偷梁换柱 / 推断过度 / 无中生有）

3. 技巧（这类题型怎么做）
   → 回忆对应题型的解题方法
   → 下次遇到类似题目怎么办

4. 举一反三（知识迁移）
   → 如果这道题问别的方向，还能怎么考？
   → 同义转述的其他可能形式
```

### 5.2 培养学生三大意识（赢在微点备考前研）

| 意识 | 内容 | 训练方法 |
|------|------|----------|
| **主旨意识** | 读文章不是为了"知道每个词的意思"，而是"知道文章在说什么" | 每读完一段用一句话概括 |
| **同义转述意识** | 正确选项几乎从不照抄原文——它用不同的词表达相同的意思 | 每道题找出原文和正确选项的"同义转述对应词" |
| **词汇意识** | 不是所有生词都需要查——有些可以猜，有些可以跳 | 区分"关键词"和"辅助词"；训练断词猜词能力 |

### 5.3 长难句分析能力

赢在微点备考前研中强调：**锁定谓语留主干**。

**步骤**：
1. 找到句子的主要谓语动词
2. 确定主语和宾语
3. 识别从句和其他修饰成分
4. 理解各成分之间的关系

```
原始：Eleven kilometres directly below the city, one of the most deadly earthquakes of the 20th century had begun, a quake that even caused damage more than 150 kilometres away in Beijing.

主干：one...earthquake...had begun
修饰1：Eleven kilometres directly below the city（地点状语）
修饰2：of the 20th century（介词短语作定语）
修饰3：a quake that...（同位语 + 定语从句）
```

### 5.4 障碍词处理能力

赢在微点总结了三种方法：

| 方法 | 适用场景 | 操作 |
|------|----------|------|
| **线索定位法** | 上下文中能找到解释 | 用冒号、破折号、同位语、举例来找解释 |
| **联旧想新法** | 生词与已知词同根/同源 | 拆解前缀+词根+后缀，联系已学词汇 |
| **拆解重组法** | 合成词 / 派生词 | 拆分复合词→分析各部分意义→结合语境确定 |
