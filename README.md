# English Teaching

用问题引导学生理解英语文章，建立语篇意识，让答案自然浮现。

## 项目结构

```
English Teaching/
├── CLAUDE.md              # AI 使用指南（新对话必读）
├── README.md              # 本文件
├── methodology/           # 方法论与研究资料
│   ├── 课程标准库/         # 课标结构化拆解
│   ├── 高考命题研究与应用/  # 陈康等专家论文 18 篇
│   └── 政策文件/           # 高考评价体系等 30+ 份
├── data/exams/            # 真题 20 套（2023-2026）
├── src/                   # 前端（待建）
├── scripts/               # 构建脚本（待建）
└── public/                # 部署产物（待建）
```
