## 第一部分：读后续写考查什么？

### 1.1 题型本质

读后续写要求考生在阅读约350词的记叙文后，根据所给的两段开头语，续写约150词。满分25分。

读后续写是实现「一核四层四翼」中**综合性**和**创新性**最典型的题型：它同时考查阅读理解能力、逻辑推理能力、创造性思维能力和语言表达能力。

### 1.2 评分五维度（陈康、张洁）

| 维度 | 高分特征（21-25分） | 评估重点 |
|------|-------------------|----------|
| 内容完整性 | 与原文情境融洽，情节发展合理，有创造性 | 协同效应（Alignment） |
| 语言准确性 | 语法结构多样，词汇丰富，错误极少 | 语言质量 |
| 篇章连贯性 | 有效使用衔接手段，段落间过渡自然 | 结构衔接 |
| 情感表达 | 情感描写细腻，人物形象丰满 | 情感层次 |
| 书写规范 | 卷面整洁，标点正确 | 卷面 |

### 1.3 我们的方法论全景

本文档把两个系统融合成一个完整的教学框架：

| 层次 | 我们已有的 | 赢在微点补充的 |
|------|-----------|---------------|
| **宏观规划** | 三维解构法 + 双轨提纲 + 连贯性设计 | 421原则 + CARE原则 |
| **微观技巧** | 十大万能句型 | 40个公式（动作8 + 情感14 + 对话5 + 心理6 + 结尾12） |
| **考场策略** | 质量自检清单 | 10个高频微场景 + 评分细则 |

## 第二部分：宏观规划 —— 从读到写的完整流程

### 2.1 三维解构法（我们的框架）

读原文时，从三个维度做分析：

```
【情节维】
- 故事背景（Setting）
- 人物关系（Characters）
- 冲突高潮（Climax）
- 故事走向（Plot direction）

【情感维】
- 每个角色的情感变化曲线
- 隐含态度和未明说的感受
- 情感基调（温暖/励志/感人/紧张）

【语言维】
- 叙事视角（第一/第三人称）
- 时态（一般过去时为主）
- 语言风格（简洁/细腻/幽默）
- 高频表达（值得在续写中呼应）
```

### 2.2 421原则（赢在微点）

读完原文后，用421原则规划续写的宏观框架：

| 要素 | 内容 | 说明 |
|------|------|------|
| **4点衔接** | | |
| 衔接1 | P1开头 → 自然承接原文结尾 + P1首句 | 不能突兀 |
| 衔接2 | P1结尾 → 自然过渡到P2首句 | 最关键的一个衔接 |
| 衔接3 | P2开头 → 从P2首句自然展开 | |
| 衔接4 | P2结尾 → 回扣原文主题 + 升华 | 全文收束 |
| **2个过渡** | | |
| 过渡1 | P1中：衔接1 → 衔接2 之间的情节和情感发展 | P1主体内容 |
| 过渡2 | P2中：衔接3 → 衔接4 之间的情节和情感发展 | P2主体内容 |
| **1个主题** | | |
| 1个主题 | 全文的主题——藏在原文标题/关键词/人物语言中 | 续写必须围绕或呼应这个主题 |

**"两段首句定一框"**：两段首句已经框定了各自的发展方向，不要偏离首句的指引。

### 2.3 CARE原则 —— 六类协同（赢在微点）

续写与原文必须在六个维度上协同：

| 协同类型 | 含义 | 操作 |
|----------|------|------|
| **主题协同** | 续写围绕同一主题，结尾呼应或升华主题 | 写作前写出"主题句" |
| **情节协同** | 续写情节是原文情节的逻辑延续 | 用三维解构法分析情节走向 |
| **人/物协同** | 人物性格、习惯动作、口头禅在续写中延续 | 写角色时"回看人物表" |
| **冲突协同** | 续写必须解决原文引入的冲突或问题 | 确认"原文有什么问题没解决" |
| **语言协同** | 用词风格、句式长短、修辞手法保持一致 | 注意原文语言特征 |
| **特定物协同** | 原文的关键物件（狗、马、信、照片等）贯穿续写 | 列出原文的"物件清单" |

### 2.4 连贯性设计（我们的框架）

在CARE六类协同的基础上，我们提炼了五种可操作的连贯性类型：

| 类型 | 操作 | 示例 |
|------|------|------|
| **人物性格延续** | 原文人物的核心性格在续写中不变 | 原文害羞 → 续写中害羞地开口 |
| **情感基调一致** | 原文的情感方向在续写中自然发展 | 危急→焦虑→释然（不是危急→搞笑） |
| **物件线索呼应** | 原文的关键物件在续写中再次出现 | 狗 → 狗引领救援 → 狗是英雄 |
| **事件因果承接** | 续写事件是原文事件的合理结果 | 原文摔倒 → 续写救援 → 康复感谢 |
| **语言风格匹配** | 句式、用词、描写密度与原文一致 | 原文多用短句 → 续写也用短句 |

### 2.5 双轨提纲（我们的课堂模板）

将421原则和连贯性设计转化为可填写的表格：

```

|------|-------------------|---------------------|----------|----------|
| ①★   | [衔接P1首句]      |                     |          |          |
| ②     |                   |                     |          |          |
| ③★   | [衔接P2首句]      |                     |          |          |

|------|-------------------|---------------------|----------|----------|
```

## 第三部分：微观技巧 —— 40个微技能公式

> 赢在微点提供了系统化的微技能公式库。我们的十大万能句型（文档末尾附录）在句式层面更精炼，赢在微点在描写功能层面更细分。两者互补。

### 3.1 动作描写（8公式）

| 公式 | 结构 | 功能 |
|------|------|------|
| **公式1** | S + did A, did B and did C | 动作链——三个以上连续动作 |
| **公式2** | S + did A and did B, 非谓语C | 动作链 + 非谓语收尾 |
| **公式3** | S + did A, 非谓语B and 非谓语C | 主动作 + 两个伴随动作 |
| **公式4** | 形容词/副词/介词短语, S + did | 用修饰语为动作铺垫 |
| **公式5** | S + did, with + 名词 + 非谓语/介词短语 | with复合结构修饰动作 |
| **公式6** | S + did, 独立主格[名词+非谓语/短语] | 独立主格修饰动作 |
| **公式7** | when/while/as + 时间状语从句, S + did | 时间状语为动作提供背景 |
| **公式8** | S + did, as if/though + 非谓语/形容词 | "好像..."为动作增添比喻 |

**与十大万能句型的对应**：公式4-6 = 我们的「with复合结构/独立主格」+「形容词作状语」；公式7 = 我们的「状语从句」；公式1-3 = 我们的「非谓语动词」。

### 3.2 情感描写（14公式）

#### 表情（公式1-3）

| 公式 | 结构 | 示例 |
|------|------|------|
| 公式1 | A look of + 情感名词 + flashed across one's face | A look of relief flashed across her face. |
| 公式2 | 情感名词 + was written all over one's face | Joy was written all over his face. |
| 公式3 | One's face + 动词 + with + 情感名词 | His face lit up with joy. Her face went pale with shock. |

#### 眼睛（公式4-6）

| 公式 | 结构 | 示例 |
|------|------|------|
| 公式4 | 情感名词 + shone/twinkled/sparkled in one's eyes | Hope sparkled in her eyes. |
| 公式5 | with one's eyes full of + 情感名词 | ...with his eyes full of gratitude |
| 公式6 | Sb. saw the + 情感名词 + in one's eyes | He saw the fear in her eyes. |

#### 身体/心脏（公式7-10）

| 公式 | 结构 | 示例 |
|------|------|------|
| 公式7 | Fear/Surprise/Shock rooted sb. to the spot. | Fear rooted him to the spot. |
| 公式8 | One's heart + 动词 + with + 情感 | Her heart pounded with excitement. His heart sank with despair. |
| 公式9 | 情感名词 + seized/swept over/flooded over + sb. | A wave of relief flooded over her. |
| 公式10 | Sb. was seized by/filled with + 情感名词 | He was consumed with guilt. |

#### 声音（公式11-12）

| 公式 | 结构 |
|------|------|
| 公式11 | Sb. heard the note of + 情感 + in one's voice |
| 公式12 | One's voice + trembled/was filled with + 情感 |

#### 情感变化/消失（公式13-14）

| 公式 | 结构 | 示例 |
|------|------|------|
| 公式13 | 情感A + gave way to / was replaced by + 情感B | Her fear gave way to relief. |
| 公式14 | 情感 + faded/melted away/disappeared | The anxiety melted away. |

### 3.3 对话描写（5公式）

对话核心句型：`"对话内容," sb. + "说"的动词 + 修饰语`

| 公式 | 修饰语类型 | 示例 |
|------|-----------|------|
| 公式1 | 声音描写（with + 情感 + in one's voice） | "Thank you," she said, with gratitude in her voice. |
| 公式2 | 情感描写（形容词/副词/with + 情感名词） | "I made it!" he shouted, overjoyed. |
| 公式3 | 表情描写（非谓语动词/with复合结构） | "I'm sorry," she whispered, tears streaming down her face. |
| 公式4 | 动作描写（非谓语动词/with复合结构/独立主格） | "Come here," he said, reaching out his hand. |
| 公式5 | 心理活动（think/wonder + 宾语从句） | "Is it true?" he asked, wondering if he had heard correctly. |

**30个替代 said 的动词**：
- 大声：explode, scream, shout, thunder, yell, roar
- 低声：breathe, murmur, whisper, sigh, stammer, gasp
- 笑哭：beam, tease, weep, sob, choke out
- 问答：demand, respond, promise, admit, add, interrupt

### 3.4 内心活动（6公式）

| 公式 | 结构 | 功能 |
|------|------|------|
| 公式1 | An idea hit/struck/occurred to sb. / It dawned on sb. that... | 突然想到 |
| 公式2 | Sth. crossed/flashed through/popped into sb.'s mind | 突然记起 |
| 公式3 | One's mind began to race / One's mind raced | 思绪飞转 |
| 公式4 | Sth. escaped sb. / Sth. slipped one's mind | 忘了某事 |
| 公式5 | What if...? / 一般/特殊疑问句 | 内心焦虑/不确定 |
| 公式6 | What/How 感叹句 | 内心感叹 |

### 3.5 结尾升华（12公式）—— 四组

#### 第一组：感悟结尾（公式1-4）

| 公式 | 结构 |
|------|------|
| 公式1 | Looking back, 主人公 + realized/learned that...not only...but also... |
| 公式2 | Never did + 主人公 / Only then did + 主人公 + realize + that...（倒装） |
| 公式3 | It was + 被强调内容 + that + 主人公 realized...（强调） |
| 公式4 | 对比反差/排比/叠词——用修辞增效 |

#### 第二组：呼应主旨（公式5-6）

| 公式 | 结构 |
|------|------|
| 公式5 | Gradually, 主人公 came to the realization that + 原文主旨句 |
| 公式6 | 原文人物 was right: 原文人物的话 + 感悟 → 话语 echoed in one's mind |

#### 第三组：主题升华（公式7-9）

| 公式 | 结构 |
|------|------|
| 公式7 | Looking back on + the + 形容词 + experience/journey, 主人公 realized that... |
| 公式8 | 谚语/名言（As the saying goes, ...） |
| 公式9 | 引用名言深化主题 |

#### 第四组：情景交融 + 画面定格（公式10-12）

| 公式 | 结构 | 特征 |
|------|------|------|
| 公式10 | With/Despite + the + adj. + sunlight/wind/snow..., sb. did | 静态场景，融情于景 |
| 公式11 | 动态场景 + 情感寓于环境 | 动态 + 情感 |
| 公式12 | 衔接部分, 主语(人物/物品) + 动作 + 升华主题 | 画面定格式——最推荐 |

## 第四部分：10个高频微场景（赢在微点）

| # | 场景 | 典型情绪曲线 | 最佳结尾 |
|---|------|-------------|----------|
| 1 | 比赛/演讲/表演 | 紧张→镇定→自豪 | 画面定格 |
| 2 | 改变/成长 | 害怕/矛盾→释然→自信 | 感悟 > 主题升华 |
| 3 | 亲情 | 害怕/冲突→释然→温暖/感恩 | 画面定格 |
| 4 | 友情 | 后悔/内疚→释然→温暖/感恩 | 画面定格 |
| 5 | 问题解决 | 焦虑→自信/释然→自豪 | 画面定格/情景交融 |
| 6 | 善行助人 | 担心→释然→温暖/感恩 | 画面定格 > 主题升华 |
| 7 | 校园生活 | 焦虑/尴尬→释然/感动→自豪/感恩 | 画面定格 |
| 8 | 遇险求生 | 恐惧→释然→感恩/自豪 | 画面定格 |
| 9 | 生日/节日 | 尴尬/担心→释然→感恩 | 情景交融 |
| 10 | 人与自然 | 担心→快乐/释然→感恩 | 画面定格 > 主题升华 |

**每个场景的写作要点**：
- 情节线：从原文情节自然延伸
- 情感线：用情感公式（14公式）细腻描摹变化
- 动作线：用动作链（8公式）营造画面感
- 结尾线：选最适合该场景的结尾公式

## 第五部分：教学应用 —— 完整课堂流程

### 5.1 15分钟课堂训练流程

```
原文速读（3 min）
  ├── 三维解构：人物表 + 矛盾 + 情感基调
  └── 写出主题句（1个主题）

连贯性设计（2 min）
  ├── 找出至少3处原文线索（人物性格/情感变化/关键物件/事件因果）
  ├── 决定在续写中如何延续/呼应
  └── 确认6类协同（CARE自检）

双轨提纲（5 min）
  ├── Para 1：3个要点（情节链 + 情绪线 + 描写手法 + 可用句式）
  ├── Para 2：3个要点（同上）
  └── 检查4点衔接是否连贯

微技能选择（2 min）
  ├── 从40公式中选至少：2个动作公式 + 2个情感公式 + 1个对话公式 + 1个结尾公式
  └── 从10个微场景中确认场景类型

升华句（1 min）
  └── 把Para 2要点③展开成一句点题句（不说教，用画面或动作收尾）

质量自检（2 min）
  └── 结构衔接 / 描写手法 / 高级句式
```

### 5.2 两套系统的分工

| 做什么 | 用哪个系统 |
