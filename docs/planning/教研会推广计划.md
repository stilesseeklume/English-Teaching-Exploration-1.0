# Seeklume 教研会推广计划

> 时间节点：约 4 周后，组长要求在英语科组教研会上推出 Seeklume
> 这是 v1 的第一次真实用户验证（**比组长 1 人反馈重要 10 倍**）
> 上游：[roadmap.md](roadmap.md)

---

## 0. 战略判断

### 这次教研会的真实意义

| 看似 | 实际 |
|---|---|
| 一次产品演示 | **v1 完成度的最终验收（PROJECT_CHARTER 第 5 节"5 位老师试用 1 个月"的批量启动）** |
| 收一堆反馈 | **决定 Sprint 2-5 真做什么的核心输入** |
| 让大家用起来 | **形成"我们科组都在用"的社会证明** |

### 期望管理（重要）

**不要**指望：
- 演示完所有老师都说"太好了"
- 一次会议就让所有人开始用
- 收到的反馈都是建设性的

**要**接受：
- 30% 老师会很感兴趣 + 给具体反馈
- 50% 老师礼貌点头 + 不真用
- 20% 老师会怀疑 / 提"挑刺"问题
- 这就是 v1 真实用户验证的正常分布

- [ ] 准备 Q&A：把组长帮想的 5 个问题 + 你自己想的 5 个先想好答案

**关键演示流程**（待你按实际情况修订）：

```
0-1 分钟  开场 + 问题陈述
          "我们讲卷子最烦什么？讲完一张题，下次同考点的题学生还错。
           因为我们的题库散在各张试卷里，没人能联起来。"

1-3 分钟  上传 Word 演示
          打开 Seeklume → 上传一份你最近讲的卷子 → 30 秒 AI 自动解析
          → 进错题本看到题目按考点分类好

3-6 分钟  迁移训练精细化演示（核心价值）
          打开一道学生常错的题 → 点抽屉"迁移训练"
          → 看到考点："现在完成时 since" + 对应必修一 U4
          → 系统自动列出近 3 年其他卷子的相同考点题
          → 一句话：你下次讲这题，可以顺手把这 5 道串起来讲

6-8 分钟  知识地图 / 教材进度 演示
          展示三视图：考点视图 / 教材视图 / 体系视图
          → 重点：教材视图能直接看到"必修一 U4 对应的考点"

8-10 分钟 收尾 + 求助
          "我们科组一起把题库做大，迁移训练就越精确。
           我做了一份问题清单，你们看完发我。
           愿意试用 1 个月的，扫码进试用群。"
```

## 3. 教研会后反馈处理：分级法

**预期反馈量**：10-20 位老师 × 1-5 条 = 30-100 条

直接全做 = 你死。必须分级。

### 分级 SOP

每条反馈拿到 → 立刻分到 4 个篮子：

| 篮子 | 标准 | 行动 |
|---|---|---|
| 🔥 **立刻修** | 影响核心使用（登录挂、上传失败、UI 错位）| 24 小时内修 |
| ⚡ **本周修** | 重要 + 多人提（如某类题精细化、教材某单元映射错）| 列入下个 sprint |
| 📋 **后续考虑** | 单人提的 feature 想法 | 加进 roadmap §3 候选清单 |
| ❌ **不做** | 跟 v1 边界冲突（如"加学生端"、"加家长端"）| 礼貌告知 "v3+ 考虑"，不承诺 |

### 关键心态

- **听到不等于必须做**
- **拒绝不等于不尊重**
- **每条反馈都回复一句"收到，谢谢"，让老师感到被听到**
- **不要立刻承诺改任何东西**——说"会在下个版本看看"

### 用 PROJECT_CHARTER 做盾牌

如果某老师要求"加听力题 / 加学生端 / 加 APP 版"等 v1 边界外的事，话术：
> 这是好主意。Seeklume 当前 v1 聚焦在"语法填空讲题"，
> 您的建议我记录在我们的产品路线图里，
> 大概会在 [v2/v3] 阶段考虑。
> v1 期间我们想先把语法填空做精，再扩展。

不解释、不辩论、不承诺。

## 4. 风险清单与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 现场演示卡死 / 网络挂 | 中 | 高 | 提前录 2-3 分钟备用视频 |
| AI 解析 Word 那次刚好失败 | 中 | 中 | 演示用预先上传好的卷子，不现场上传 |
| 老师追问"跟 XX APP 区别" | 高 | 中 | 准备一句话："我们专做高考语法填空 + 考点精细 + 跨卷迁移" |
| 老师问"收费吗" | 高 | 中 | "目前免费，未来不确定，但承诺现有用户长期免费" |
| 老师问"数据怎么保护" | 中 | 中 | "Supabase 行级安全，只有你能看你自己的题" |
| 反馈太杂没法处理 | 高 | 中 | 用本文档 §3 分级 SOP |
| 教研会推完没人用 | 中 | 高 | 第 5 周主动回访 3 位"看起来感兴趣的"，问"上次会后用了吗" |
