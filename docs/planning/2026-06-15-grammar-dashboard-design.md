# 语法填空 · 班级看板 & 学生看板 & 错题本 —— 设计文档

> 状态：设计定稿 · 2026-06-15（图表 = Chart.js；转实现计划）
> 关联：升级现有「班级工作台」(`error-profile` 页)，取代当前单一「考点正确率排行」；并恢复先前砍掉的错题本（导入方式全换）。

---

## 1. 背景与目标

**现状问题**：当前班级画像 = 一条「精细考点正确率排行」。用户反馈"感觉不是很 ok"——只给干巴巴的百分比，没接教学：不说为什么错、该怎么讲、长期谁进谁退、下一步学什么。它是**统计**，不是**教学**。

**目标**：
- 把画像升级成两块**数据看板**（班级 / 学生），围绕**分数**和**考点**两条线诊断，"长期成长 + 该学什么"当头条，并能从任一弱信号**点进原题、接讲评、出迁移**。
- **恢复错题本**（班级 + 个人），但导入方式从"单独导"改为"**从成绩自动长出来 + 手动补**"，作题目级原题册，与考点级看板互补。

**信息层级（用户拍板）**：每个看板**长期成长/处方当头条**，**本次快照在下**做佐证。

## 2. 落点

- 升级现有「班级工作台」(`error-profile` 页)：Tab `考点视角`→**班级看板**；Tab `学生视角`（选学生后）→**学生看板**；`学生管理` 不变；班级/卷次选择骨架保留。
- **恢复 dock「错题本」入口**（先前下线，本次请回），独立页（§8）。
- 现在的正确率排行被这两套看板取代。

## 3. 数据基础（零新数据）

全部从云端 `exam_results` 实算，不新增存储、不重导卷。

- **得分**：每空 1.5 分、非对即错 → 某生某卷得分 = `right.length × 1.5`，满分 15。
- **阈值**：及格 ≥ 9（60%）、优秀 ≥ 12（80%）；**错题本自动入册线：班级正确率 < 50%**。
- **缺考**：`blank[]` 区分，不计入得分率分母。
- **考点**：每题精细 `fine_category` 归并到 §4 的 10 个看板考点；老题无 fine 回退 `category`。
- **错题本存储**：复用既有 `error_book`（Supabase 表 + localStorage，先前停用未删）作底，导入逻辑换新。
- **数据局限（影响北极星，见 §13）**：`exam_results` 只存每题对/错（题号），**不存学生实际填了什么**，故本版做不到"错法聚类"。

---

## 4. 考点轴（10 类，两组）

每道题靠精细 tag 自动归到这 10 类。看板/热力图/雷达/矩阵/错题本分类全用这套；精细 tag 只留给「一键迁移出题」。

| 组 | 看板考点 | 来自题库（fine_category / 粗类） |
|---|---|---|
| **有提示·词形变化** | 时态 | `pred-tense` |
| | 谓语其他 | `pred-passive` + `pred-agreement` |
| | 非谓语 | 不定式 / 现在分词 / 过去分词 |
| | 词性转换 | 形容词 / 副词 / 名词派生 / 比较级 |
| | 名词数词 | 单复数 / 数词 |
| **无提示·功能词** | 冠词 | a/an / the / 零冠词 |
| | 介词 | 介词 |
| | 代词 | 各类代词 |
| | 连词逻辑 | 并列 / 逻辑连词 |
| | 从句 | 定语从句 + 名词性从句 + 状语从句 |

**分组依据**：语法填空"有提示（考变形）/ 无提示（考功能词）"的天然分水岭，两半解题思维不同。
**映射真源**：`boardCatOf(fineOrCat) → 10类之一`，单一函数，聚合 + 名称 + 错题本分类共用。

## 5. 班级看板（自上而下）

1. **头条 · 长期成长与处方**：考点成长矩阵（水平×趋势 3×3）+ 班级教学处方（排序 to-do，每条带「一键出题」「看原题」「讲评要点」）。
2. **核心指标卡**：本次均分 / 历史最高·最低 / 及格率(≥9) / 优秀率(≥12)。
3. **考点热力图**：10 考点 × 历次，格子=得分率（红<50/黄50-69/绿≥70/灰=未考或数据不足）；**格子可点 → 原题**。
4. **班级进步轨迹**：均分折线 + 回归趋势线（样本不足不画，§9.2）。
5. **分数分布**：直方图（0-3/…/12-15）+ 多次叠加看收窄。
6. **本次重点**：自动揪最低 3 考点 + 对比上次；考点可点 → 原题。
7. **错题本摘要入口**：「本班错题 N 道 →」点进错题本页（§8）。

---

## 6. 学生看板（自上而下）

> 本版 = **老师视角**（点开看某学生）。学生自助（学号登录）是未来事项（§13）。

1. **头条 · 个人成长与处方**：个人成长矩阵 + 个人处方（排序 +「一键练」「看原题」）+ 成长里程碑。
2. **个人成绩轨迹**：折线 + 班级均分线。
3. **考点雷达**：10 考点累计得分率，个人 vs 班级均值。
4. **考点明细表**：每考点历次得分率，标"从没做好过"；错题可点 → 原题。
5. **与班级对比**：每考点 ✅高于 / ❌低于均值。
6. **个人诊断标签**：自动一句话画像。
7. **个人错题本入口**：「该生错题 N 道 →」点进错题本页（§8）。

---

## 7. 从看板到教学（发射台）

看板是教学发射台。任一弱信号（热力图格子 / 本次重点 / 明细错题 / 处方条目）可点进：
- **看原题**：该卷该空原文片段 + 答案 + 解析。**前提**：卷在题库或已导备课卷；纯分数无题面 → 按钮置灰。
- **讲评要点**：跳该考点方法论导问/常见陷阱（缝合"分析"与"教学内容"）。
- **一键迁移**：出该考点同类题（复用现有引擎）。
- **错题本**：弱题自动入册（§8），可复习/再练。
- **闭环（阶段 D）**：老师对弱考点开过迁移/标"重点讲"后，下次考完自动回看起没起色（"介词 46%→55%"），对接方法论"高考后效"，形成反馈回路。

## 8. 错题本（班级 + 个人）

> 先前砍掉的错题本请回来，**导入方式全换**：不再单独导一遍，而是**从成绩自动长出来 + 手动补**。错题本 = **题目级原题册**，与考点级看板互补（看板说"哪类弱"，错题本给"具体哪几道题"）。

**两册**：
- **班级错题本**：自动收录"全班正确率 < 50% 的题"——全班集体栽的原题，拿来重讲/出迁移。
- **个人错题本**：自动收录"某学生做错的题"，每生一册。本版老师视角查看；未来学生学号登录自看（§13）。

**手动补充**：老师可额外手选任意题丢进班级/个人错题本（保留旧功能）。

**现身（用户拍板：两者都要）**：
- **独立页**：恢复 dock「错题本」入口，页内分 班级错题本 / 个人错题本（选学生）。
- **看板入口**：班级/学生看板各给摘要入口（§5.7 / §6.7）点进。

**每道错题携带**：原文片段 + 空 + 答案 + 解析 + 考点 + 来源卷次 +（班级册）当时正确率 /（个人册）哪些次错。可直接「讲题」或「一键迁移」。

**题面前提**（同 §7）：入册要有题面 → 卷在题库或已导备课卷。纯分数无卷 → 记题号但置灰提示"该卷未导题面"。

**存储**：复用 `error_book`（表 + localStorage）作底；班级册键到班级，个人册键到**学号**（名字不上云）。页面/讲题逻辑从 git 历史捞回复用，导入换新。

## 9. 核心算法

### 9.1 得分与聚合（纯函数，可单测）
- `examScore(row) = right.length × 1.5`；`catRate(rows, 考点) = 对/(对+错)`，缺考不计分母。
- 班级 per(卷,考点) = 平均得分率；累计 per 考点 = 全历次平均。
- `classCatRate < 50%` → 该题入班级错题本；`student wrong` → 入个人错题本。

### 9.2 水平 × 趋势 分类（成长矩阵核心，含诚实与冷启动）
- **水平**：累计得分率 → 高(≥70)/中(50-69)/低(<50)。
- **趋势**：历次得分率线性回归斜率 → 升/平/降。
- **样本诚实（硬规则）**：某考点**有效考次 < 3** → "数据不足"，不判趋势、不贴状态、不画趋势线，矩阵灰显。
- **冷启动**：新班从第 1 卷起就要有用（本次指标 + 重点 + 看原题 + 错题本先到位），趋势/矩阵/处方随历史变厚再点亮。每块独立判"够不够数据"。
- **状态映射**：
  | 水平＼趋势 | 升 ↑ | 平 → | 降 ↓ |
  |---|---|---|---|
  | 高 | 优秀(免讲) | 稳固(免讲) | 高位回落(查因) |
  | 中 | 良性(保持) | 待突破(加练) | 滑坡(注意) |
  | 低 | 在好转(继续) | **顽固盲点(系统重讲)** | **恶化(优先抢救)** |
- **处方排序**：红区按 (越低 + 越在恶化 + 持续越久) 排前。

### 9.3 诊断规则（决策表）
| 现象 | 结论/标签 |
|---|---|
| 考点得分率 < 50% | 需要重讲（+入班级错题本） |
| 某考点连续 ≥3 次低 | 系统性盲点（非偶发） |
| 高分生也错 | 题本身难 / 教学未覆盖 |
| 只有低分生错 | 基础薄弱，分层教学 |
| 全班均分下滑 | 查该段教学节奏/难度 |
| 个人历次方差大 | 状态不稳，需关注 |

## 10. 图表实现

- **图表库（已定 = Chart.js via CDN）**：画折线/直方/雷达——一个配置出图，自带悬停看数值 + 动画 + 自适应；mockup 即其效果。代价：① 加一个 CDN 依赖（本就联网同步，可接受）；② canvas 读不到主题变量，**暗色需手动适配**（按 `prefers-color-scheme` 切一套 hex）。
- **HTML/SVG（不进 Chart.js）**：核心指标卡 / 诊断标签 / 考点热力图 / 成长矩阵 / 错题本列表 用 HTML + 语义色变量（暗色自动适配）。

## 11. 分阶段（独立 commit、可单独发布）

- **A · 数据层**：`boardCatOf` 映射 + 得分/聚合/趋势分类(含样本诚实)/处方排序/<50%与个人错判定 纯函数（全可单测）。地基。
- **B · 班级看板**：头条 + 指标卡 + 热力图 + 轨迹 + 分布 + 重点；含看原题 + 接方法论；冷启动降级。
- **C · 学生看板**：头条 + 轨迹 + 雷达 + 明细 + 对比 + 标签；含看原题。
- **D · 闭环（提升项）**：记"重点讲/已迁移"，下次回看改善度，挂迁移。
- **E · 错题本（恢复 + 提升）**：复活错题本页/存储（git 捞）+ 自动导入(<50%/个人错) + 手动补 + 看板摘要入口 + 讲题/迁移。

每阶段收口：`test:unit` 绿 + `test:smoke` 绿 + preview 截图。

## 12. 风险与边界

- **老数据降级**：无 fine_category 回退 category，映射兜底。
- **样本 / 冷启动**：< 3 次显"数据不足"不画趋势；新班第 1 卷起可用。
- **稀疏考点**：功能词类单卷常缺考，灰格多 = 正常。
- **看原题 / 入错题本前提**：卷需在题库或已导备课卷；纯分数无题面 → 置灰，不报错。
- **错题本复活**：从 git 历史捞页面/讲题逻辑；`error_book` 存储未删可直接接；注意先前删除的 cloud-sync 猴补丁等需重新接好。
- **guest 态**：看板/错题本需登录拉数据，给登录引导、不报错。

## 13. 未来方向（北极星 / 不在本版）

- **错法诊断（北极星，待数据采集）**：录入时捕获每空学生实际填的答案 → 错法聚类（"60% 错填成 in"）。真正从"统计"跨到"诊断"，需改数据采集，难度大、单独立项。
- **学生端（学号登录）**：老师设学号 → 学生学号登录，自看个人看板 + 个人错题本 + 收一键练。学号可上云（**名字永不上云**不变），个人错题本已按学号键、为此预留。
- **YAGNI（本版不做）**：不动导入流程、不动迁移引擎内部、不动 `exam_results` schema；不做跨班横向对比、家长视图、导出报告。
