Seeklume 隐私说明

最后更新：2026-05-28

Seeklume 当前面向高中英语教师，用于语法填空讲评、错题本、备课资料和 AI 辅助解析。我们只收集维持这些功能所必需的数据。

我们收集什么

  • 账户信息：邮箱、用户名、登录状态。
  • 用户内容：你保存的错题本、备课资料和导入内容。
  • 反馈信息：你主动提交的问题、建议、当前页面和浏览器信息。
  • 运行事件：页面错误、同步失败、AI 上传失败等最小化诊断信息。

我们不收集什么

  • 不保存你的密码明文。
  • 不在公开仓库保存学生姓名、班级、成绩、画像等隐私数据。
  • 反馈和错误日志默认不保存完整学生成绩或大段敏感内容。

数据用来做什么

  • 登录和跨设备同步。
  • 保存错题本和备课资料。
  • 排查系统错误、AI 解析失败和同步问题。
  • 根据真实反馈改进产品。

谁能访问

普通用户只能访问自己的数据。管理员可在必要时查看反馈、错误事件和用户数据，用于排查问题、改进系统和处理支持请求。

删除与导出

登录后可在“账户设置”中自助导出错题本和备课资料，也可以清空自己的学习数据。账号删除需要通过“申请删除账号”提交请求，管理员会按请求处理账号和相关云端数据。

第三方服务

Seeklume 使用 Supabase 提供登录、数据库和 Edge Functions；使用 DeepSeek API 做 AI 解析和助手回复；通过 GitHub Pages 和 Cloudflare 提供网站访问。

联系我们

如需报告隐私问题，或需要管理员协助删除账号，请通过站内反馈入口联系管理员。
