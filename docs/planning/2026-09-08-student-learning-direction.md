# Seeklume 学生英语学习方向

> 确认日期：2026-09-08
> 状态：当前产品方向

## 一句话定位

Seeklume 是面向自有班级高中学生的英语学习网站，先用文本与音频帮助学生完成精听、阅读、Shadow Reading、录音回听和专项练习。

## 当前产品边界

- 学生是主要用户，首页与主导航使用学生语言。
- Shadow Reading 是第一个核心学习模块。
- 语法填空保留为专项练习，不再是产品主线。
- 教师管理工具暂不开发；班级工作台、礼堂排座等非英语学习功能不出现在学生界面，代码留档。
- 视频模块暂不做。内容优先使用原创、已授权或明确开放授权的文本与音频。
- 学生录音第一版不上传，只在当前页面回听；完成状态保存在本机。

## 第一阶段学习闭环

```text
选择文章
  → 听原音
  → 查看英文/翻译
  → 逐句 Shadow Reading
  → 录下自己的声音
  → 回听对比
  → 标记完成
```

## 小步演进

1. 先解决 Windows 班级电脑音频首词吞音和播放稳定性。
2. 完成 Shadow Reading 改名、录音回听和本机完成记录。
3. 将文章内容、媒体清单和页面播放逻辑分离，让新增内容不需复制整个页面。
4. 用真实 Windows Chrome/Edge 和手机做小范围班级验证。
5. 根据学生使用反馈再决定视频、账号同步和更复杂的评估功能。

## 非当前范围

- 教师后台、作业布置、班级统计。
- AI 发音评分。
- 用户上传视频或视频托管。
- 复杂的内容管理后台。
- 与英语学习无直接关系的学校行政工具。
