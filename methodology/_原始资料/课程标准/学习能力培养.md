# 📚 学习能力培养

> **定义**：学习能力指学生积极运用和主动调适英语学习策略、拓宽英语学习渠道、努力提升英语学习效率的意识和能力。

## 📖 基本定位

### 在核心素养体系中的角色
- **地位**：学习能力构成英语学科核心素养的**发展条件**
- **功能**：学习能力是学生可持续发展的基础保障
- **作用**：学习能力的培养有助于学生做好英语学习的自我管理，养成良好的学习习惯，多渠道获取学习资源，自主、高效地开展学习

### 学习能力构成维度
1. **策略运用能力**：选择和使用适当的学习策略
2. **策略调适能力**：根据学习情况调整学习策略
3. **资源获取能力**：多渠道获取学习资源
4. **效率提升能力**：提高学习效率的方法和意识
5. **自我管理能力**：规划、监控、评价学习过程

---

## 🎯 学习能力目标

### 总体目标
树立正确的英语学习观，保持对英语学习的兴趣，具有明确的学习目标，能够多渠道获取英语学习资源，有效规划学习时间和学习任务，选择恰当的策略与方法，监控、评价、反思和调整自己的学习内容和进程，逐步提高使用英语学习其他学科知识的意识和能力。

### 具体目标分解
1. **学习观培养**：树立正确的英语学习观
2. **兴趣保持**：保持对英语学习的持久兴趣
3. **目标设定**：具有明确的学习目标
4. **资源获取**：多渠道获取英语学习资源
5. **规划能力**：有效规划学习时间和学习任务
6. **策略选择**：选择恰当的学习策略与方法
7. **监控能力**：监控自己的学习内容和进程
8. **评价能力**：评价学习效果和策略有效性
9. **反思能力**：反思学习过程并进行调整
10. **迁移能力**：提高使用英语学习其他学科知识的意识和能力

## 📊 学习能力水平划分

> 注：详细水平划分参见[[附录1 英语学科核心素养水平划分]]。以下为摘要：

### 水平一（基础水平）
- 能在教师指导下使用基本的学习策略
- 对英语学习保持一定的兴趣
- 能完成教师布置的学习任务
- 初步形成学习英语的意识和习惯

### 水平二（发展水平）
- 能根据学习任务选择适当的学习策略
- 主动保持英语学习兴趣
- 能制定简单的学习计划并实施
- 能利用多种资源辅助学习
- 初步具备学习自我监控能力

### 水平三（提高水平）
- 能灵活调适学习策略以适应不同需求
- 具有强烈的英语学习内在动机
- 能制定系统的学习规划并有效实施
- 能创造性地利用各种学习资源
- 具备较强的学习自我管理能力
- 能将英语学习能力迁移到其他领域

## 🔄 与其他素养的关系

### 学习能力 → 语言能力
- 高效学习能力促进语言能力的快速发展
- 学习策略的运用提高语言学习效率
- 自主学习能力支持语言能力的持续发展

### 学习能力 → 文化意识
- 学习能力支持跨文化知识的自主获取
- 学习策略帮助理解和内化文化内容
- 自主学习促进文化意识的主动建构

### 学习能力 → 思维品质
- 学习过程本身就是思维训练过程
- 学习策略的选择需要思维能力
- 自我监控和反思是高级思维活动

### 学习能力 ← 其他素养
- 语言能力为学习提供工具基础
- 文化意识激发学习兴趣和动机
- 思维品质提高学习策略的有效性

## 🏫 教学实施建议

### 学习能力培养原则
1. **主体性原则**：尊重学生主体地位，培养自主学习能力
2. **策略性原则**：显性教授学习策略，培养策略运用意识
3. **渐进性原则**：从教师指导到学生自主，逐步放手
4. **差异性原则**：尊重个体差异，提供个性化指导

### 学习策略教学
- **认知策略**：记忆策略、理解策略、应用策略
- **元认知策略**：计划策略、监控策略、评价策略
- **情感策略**：动机维持策略、焦虑调节策略
- **社交策略**：合作学习策略、交流策略

### 自主学习环境创设
1. **资源环境**：提供丰富多样的学习资源
2. **时间环境**：给予学生自主安排学习时间的空间
3. **空间环境**：创设有利于自主学习的学习空间
4. **技术支持**：利用技术工具支持自主学习

### 学习指导方式
- **示范指导**：教师示范学习策略的运用
- **过程指导**：在学习过程中提供针对性指导
- **同伴指导**：通过同伴互助促进学习能力发展
- **自我指导**：培养学生自我指导的能力

### 评价建议
1. **过程评价**：关注学习策略的运用过程
2. **成果评价**：评价自主学习成果的质量
3. **发展评价**：关注学习能力的发展变化
4. **自我评价**：引导学生进行学习自我评价
