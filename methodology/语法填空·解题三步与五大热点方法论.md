# 语法填空·解题三步与五大热点方法论

> 综合来源：现有语法填空方法论 + 赢在微点二轮复习（专题三 热点1-4）+ 陈康等论文

---

## 第一部分：语法填空考查什么？

### 1.1 核心能力定位

语法填空考查两种能力：
1. **语法分析能力**：分析句子结构，判断空格功能
2. **语境理解能力**：根据上下文确定词形和词义

两者缺一不可。只看空格不管上下文是学生最常见的错误。

### 1.2 命题特征（来自赢在微点）

- 以**动词**为最重要考点（谓语 + 非谓语 = 约4-5空，占总分40-50%）
- **词形变化**（名词、形容词、副词、数词）占约3-4空
- **小词**（冠词、代词、介词、连词）占约2-3空
- 通常在一篇约200词的短文中设10空

## 第二部分：解题三步（我们的框架）

### Step 1：分析句子结构

**核心操作**：找主干（主谓宾）。

三种长难句模式（赢在微点）：

| 类型 | 特征 | 破解方法 |
|------|------|----------|
| 非核心成分过多 | 插入语、定语、状语、同位语太多 | 锁定主谓，去掉修饰成分，看清句子骨架 |
| 含多个主谓结构 | 多个动词，难以分辨 | 每个主谓结构 = 一个分句；分句之间必须有连词 |
| 多个从句套用 | 从句中再套从句 | 根据连接词数量和主谓结构数量，理清主从句层次 |

**学生指令**：
1. 先找句子的谓语动词（有时需要跳过非谓语）
2. 找主语（谁/什么做的这个动作）
3. 找宾语/表语（动作的对象/主语的特征）
4. 其他成分都是修饰

### Step 2：判断空格功能

| 空格可能作什么成分 | 应该填什么 |
|-------------------|-----------|
| 谓语 | 动词的时态、语态形式 |
| 非谓语（定语/状语/补语/主语/宾语/表语） | doing / done / to do |
| 主语/宾语/表语 | 名词 / 代词 / 名词性从句连接词 |
| 定语 | 形容词 / 定语从句连接词 |
| 状语 | 副词 / 状语从句连接词 |
| 连接词 | 并列连词 / 从属连词 |

### Step 3：确定词形变化

在确定功能和词类后，根据：
- **时态标志词** 或 **上下文时态一致性** → 确定时态
- **与主语的关系** → 确定语态（主动/被动）
- **与前后词的逻辑关系** → 确定非谓语形式
- **单个/多个** → 确定名词单复数
- **比较意义** → 确定比较级/最高级

## 第三部分：五大热点详解（赢在微点）

### 热点1：谓语动词 —— 四技巧搞定

#### 技巧1：时间状语判断法

有显性时间标志词时，直接判断时态：

| 时间标志词 | → 时态 |
|-----------|--------|
| now, at present, Look!, Listen! | 现在进行时 |
| yesterday, ...ago, the other day | 一般过去时 |
| since + 过去时间点, ever since, so far, up to now, recently | 现在完成时 |
| by + 过去时间点, by the end of + 过去时间 | 过去完成时 |
| tomorrow, next week, in the future | 一般将来时 |
| by + 将来时间点 | 将来完成时 |

#### 技巧2：参考语境和并列谓语

没有显性时间标志词时：
1. **看上下文时态**：分析前后句的谓语动词时态，判断动作发生的时间顺序
2. **看并列谓语**：如果 and, but, or 连接两个或多个并列谓语，它们的时态必须一致

#### 技巧3：时态呼应判断法

| 从句类型 | 时态呼应规则 |
|----------|-------------|
| 时间/条件状语从句 | 主将从现（主句将来时，从句现在时） |
| 宾语从句 | 主句过去时 → 从句用过去的某种时态（客观真理除外） |
| 定语从句 | 主从句时态通常一致 |

#### 技巧4：固定句型判断法

| 句型 | 时态 |
|------|------|
| It/This/That is + the + 序数词 + time + that... | 从句用现在完成时 |
| It/This/That was + the + 序数词 + time + that... | 从句用过去完成时 |
| It is/has been + 时间段 + since... | since从句用一般过去时 |
| was/were doing sth. when sb. did sth. | 前半句过去进行，后半句一般过去 |
| Hardly had sb. done sth. when sb. did sth. | 前半句过去完成，后半句一般过去 |

#### 语态判断

**核心原则**：主语执行动作 → 主动；主语承受动作 → 被动。

**不能用于被动语态**：系动词（be/become/feel/seem）、不及物动词（happen/occur/belong to/remain）

#### 主谓一致

| 原则 | 规则 |
|------|------|
| **一致原则**（语法一致） | 主语单数 → 动词单数；主语复数 → 动词复数 |
| **就近原则** | or, either...or..., neither...nor..., not only...but also..., there be → 动词与最近的名词一致 |
| **就远原则** | A + with/along with/together with/in addition to/as well as/besides + B → 动词与A一致<br>A + except/but + B → 动词与A一致 |

---

### 热点2：非谓语动词 —— 关系分析法

**总原则**：句中已有谓语动词 → 用非谓语动词。主动关系 → doing；被动关系 → done；目的 → to do。

#### 考法1：作状语和补语

**状语** = 句意 → 逻辑 → 先后关系

| 状语类型 | 形式 |
|----------|------|
| 目的状语 | to do |
| 结果状语 | too...to do, enough...to do, so...as to do |
| 原因状语 | 主动：doing；被动：done |
| 时间/伴随/方式/条件/让步 | 根据与主语的逻辑关系：doing（主动）/ done（被动） |

**补语** = 固定搭配

| 动词类型 | 搭配 |
|----------|------|
| 使役动词 | make + sb. + do；get + sb. + to do；have + sb. + do/doing/done |
| 感官动词 | see/watch/notice/observe/hear + sb. + do/doing/done |
| 请求类动词 | allow/encourage/expect/forbid/invite/persuade/tell + sb. + to do |
| with/without | with + n. + doing/done/to do（偶尔出现） |

#### 考法2：作定语

| 关系类型 | 形式 | 示例 |
|----------|------|------|
| 被修饰词是逻辑主语，表将来 | to do | the first person to arrive |
| 被修饰词是逻辑主语，表主动/进行 | doing | the sleeping boy |
| 被修饰词是逻辑宾语，表被动/完成 | done | the broken window |
| 被修饰词是逻辑宾语，表被动/将来 | to be done | the question to be discussed |

**提示词法**：
- 序数词 / the last / the only + 名词 + to do
- 抽象名词（plan, promise, ability, chance, effort）+ to do

#### 考法3：作宾语

| 搭配 | 示例 |
|------|------|
| 介词 + doing | by doing, without doing |
| 某些动词 + to do | agree, choose, decide, expect, hope, manage, offer, promise, refuse, want |
| 某些动词 + doing | avoid, consider, enjoy, deny, mind, miss, practice, suggest, feel like, look forward to |
| 两种形式意义不变 | begin/start/continue + to do = 开始/继续做 |
| 两种形式意义不同 | remember to do（记得要做）/ doing（记得做过）; forget to do（忘了要做）/ doing（忘了做过）; stop to do（停下来去做）/ doing（停止做）; try to do（努力做）/ doing（尝试做） |
| 主动形式被动意义 | need/require/want/deserve + doing = 需要被... |

#### 考法4：作主语和表语

| 用法 | 形式选择 |
|------|----------|
| 抽象/习惯性动作 | doing |
| 具体的一次动作 | to do |
| It's + adj. + ... | to do（It's hard to say.） |
| It's no use/good/fun... | doing（It's no use crying.） |

### 热点3：词形变化 —— 名词、形容词、副词、数词

#### 如何判断"此处需要名词"？

1. 看空格前的标志：冠词（a/an/the）、指示代词（this/that/these/those）、形容词、物主代词（my/his/her）→ 后跟名词
2. 看句子成分：主语位置、及物动词后的宾语位置、系动词后的表语位置

#### 如何判断"此处需要形容词"？

1. 系动词（be/become/feel/go/grow/look/lie/keep/prove/remain/stand）后
2. 名词前作定语
3. 复合不定代词后（something interesting）
4. 宾语补足语位置：make/find/consider/leave + 宾语 + 形容词

#### 如何判断"此处需要副词"？

1. 修饰形容词/副词：程度修饰
2. 修饰动词/介词短语：方式修饰
3. 修饰整个句子：句子开头

#### 如何判断"此处需要比较级/最高级"？

| 标志 | → 形式 |
|------|--------|
| than | 比较级 |
| much/far/even/a little/a bit/a lot + | 比较级 |
| as + ... + as | 原级 |
| one of the / the + 序数词 + | 最高级 |
| the + 比较级..., the + 比较级... | 比较级 |
| 比较级 + and + 比较级 | 比较级 |
| 无显性标志但有比较意义 | 比较级 |

#### 形容词→副词转换规则速记

1. 一般 + -ly（quick→quickly）
2. 辅音+le结尾：去e + -y（terrible→terribly）
3. 辅音+y结尾：变y为i + -ly（happy→happily）
4. -ic结尾：+ -ally（basic→basically, public→publicly除外）
5. -ll结尾：+ -y（full→fully）

#### 名词复数判断

看到这些词，后面填复数：these, those, many, several, (a) few, a number of, hundreds of, all, both, other, different, various, one of the, among, 数字≥2

#### 反义词判断

当上下文意思需要否定时：
- 前缀：dis-, un-, il-, ab-, ir-, in-, mis-
- 后缀：-less

### 热点4：小词 —— 冠词、代词、介词

#### 冠词判断

**用 the 的情况**：特指双熟悉，上文已提及。世上独无二，序数最高级。西洋乐器前。

**用 a/an 的情况**：泛指一类，与one同义表"一"，元音音素前用an。

**如果需要填冠词**：
- `___ + 可数名词单数` → a/an
- `___ + 名词 + of/that/which定语（特定指代）` → the
- 固定搭配：at a loss, a waste of..., catch sb. by the + 身体部位

#### 代词判断

**根据句子成分判断用哪种代词**：

| 成分 | 用什么代词 |
|------|-----------|
| 主语 | 主格（I, we, he, she, they） |
| 宾语（动词/介词后） | 宾格（me, us, him, her, them） |
| 定语（名词前） | 形容词性物主代词（my, our, his, her, their） |
| 主语/宾语与主语相同 | 反身代词（myself, himself, themselves） |

#### 介词判断

**两步走**：
1. 判断是否需要介词：如果空格后是名词/代词/动名词 → 可能需要介词
2. 根据搭配或意义选择介词：

| 常见介词 | 含义/场景 |
|----------|----------|
| for | 方向、目的、获得、持续时长 |
| in | + 时间（将来）、+ 语言/材料/方式 |
| by | + 交通/通讯工具、+ 方式、+ 差值（by a margin of） |
| with | 拥有、使用（具体工具）、伴随、原因 |
| beyond | 超出（beyond recognition / beyond expectations） |
| as | 作为（work as, serve as, regard...as） |

### 热点5：句子类型 —— 并列连词、三大从句、特殊句式

#### 考法1：并列连词

**核心原则**："对等成分 + 并列连词 + 对等成分"——连词两边必须平行。

| 连词 | 关系 |
|------|------|
| and | 并列（同向） |
| but | 转折（反向） |
| or | 选择 |

#### 考法2：定语从句

**三步判断法**：
1. 找出先行词（被修饰的名词/代词）
2. 分析从句缺少什么成分
3. 缺主/宾语 → 关系代词（that/which/who/whom）；缺状语 → 关系副词（when/where/why）；表所属 → whose

**特殊规则**：
- 抽象地点名词（point, situation, case, stage, position, job）作状语时用 where
- 介词后用 which/whom
- 非限制性定语从句不能用 that
- 只能用 that 的情况：先行词有all/little/everything等、最高级+先行词、序数词+先行词、先行词包含人和物

#### 考法3：名词性从句

**两步判断法**：
1. 分析从句成分是否完整
2. 根据句意确定连接词

| 从句缺少成分 | → 连接词 |
|-------------|---------|
| 缺主语，指物 | what |
| 缺主语/宾语/表语 | what/which/who(ever) |
| 不缺成分，表"是否" | whether/if |
| 不缺成分，陈述事实 | that |
| 不缺成分，表原因 | why / because |

**四个高频句型**：
- That is because...（这是因为...）
- That is why...（这就是为什么...）
- The reason is that...（原因是...）
- There is no doubt that...（毫无疑问...）

#### 考法4：状语从句

**句意判断法**：根据主从句意义关系选择连接词
- 条件：if, unless, once, as long as
- 原因：because, as, since, now that
- 让步：though, although, while, even if
- 地点：where, wherever

**时间先后法**：
- 同时：when, whenever, while, as
- 紧接着：as soon as, the minute, immediately, once
- 先后：before, after
- 持续至今：since

#### 考法5：特殊句式

**强调句判断**：去掉"It is/was...that/who..."后，句子结构仍然完整 → 是强调句

**状语从句省略**（同时满足两个条件）：
1. 从句含有be动词形式
2. 主从句主语一致或从句主语是it
→ 可省略从句的"主语+be动词"

## 第四部分：教学应用

### 4.1 语法填空导问流程

**第一层：文体与主题**
- 快速浏览全文，判断文体（记叙文 / 说明文）
- 这篇文章主要在说什么？

**第二层：句子结构分析**
- 这个句子的主干是什么？（主谓宾）
- 空格在这个句子中作什么成分？
- 这个句子是简单句还是复合句？（看有几个主谓结构）

**第三层：语法判断**
- 如果是谓语：看时间标志词 + 主谓一致 + 主被动
- 如果是非谓语：看与主语/被修饰词的逻辑关系
- 如果是词形转换：看空格位置=判断词性→看上下文=判断形式

### 4.2 学生常见错误

| 错误类型 | 表现 | 对策 |
|----------|------|------|
| 不看上下文 | 看到时间状语就直接填对应时态，但忽略主谓一致 | 填完后检查主语是单数还是复数 |
| 非谓语混乱 | 分不清该用 doing 还是 to do | 先判断"主动还是被动"→再考虑"已发生还是将来" |
| 词性误判 | 形容词填成副词（或反之） | 先明确空格作什么成分，再决定词性 |
| 忽略句间逻辑 | 并列连词填错（and填成but） | 翻译前后两句的意思，判断是同向还是反向 |

### 4.3 考前速记口诀

```
谓语动词四步走：时间标志 → 语境时态 → 主谓一致 → 主被动
非谓语看关系：主动doing被动done，目的都用to do
词形变化看位置：名词主语宾语，形容词定语表语，副词修饰非名词
小词判断看搭配：冠词看特指泛指，介词看固定搭配，代词看人称数
从句连接分两步：缺什么补什么，不缺看句意
```
