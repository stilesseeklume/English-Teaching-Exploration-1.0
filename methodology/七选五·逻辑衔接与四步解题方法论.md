# 七选五·逻辑衔接与四步解题方法论

> 综合来源：赢在微点二轮复习（专题五 第1-2讲）+ 陈康等论文（阅读理解能力5：理解文章结构/衔接）+ 项目三层导问框架

---

## 第一部分：七选五考查什么？

### 1.1 题型本质

七选五考查的是**语篇衔接与连贯能力**——识别句子之间、段落之间的逻辑关系，在5个空白处（段首/段中/段尾）从7个选项中选出最合适的一项。

与完形填空（词级衔接）不同，七选五考查的是**句级衔接**。

### 1.2 陈康框架中的定位

七选五对应陈康阅读7项能力中的第5项：**理解文章结构/衔接**。

| 评价维度 | 在七选五中的体现 |
|----------|-----------------|
| 关键能力 | 语篇分析能力、逻辑推理能力 |
| 必备知识 | 语篇知识（衔接与连贯）、词汇知识（同义复现） |
| 综合性 | 需要同时分析词汇衔接 + 逻辑关系 + 句式结构 + 情感色彩 |
| 应用性 | 还原完整语篇的实际能力 |

### 1.3 文章类型与选项功能

**文章以说明文为主**，偶尔考记叙文。两种呈现形式：带小标题（较易）和不带小标题（较难）。

**选项的四种功能**：

| 功能 | 通常位置 | 特征 |
|------|----------|------|
| 主旨概括句 | 段首 | 概括整段内容 |
| 总结归纳句 | 段尾 | 总结前文 |
| 衔接过渡句 | 段中 | 承上启下 |
| 细节支撑句 | 段中 | 对前句的解释/举例/递进 |

### 1.4 2025高考趋势

- 显性逻辑连接词减少，隐含逻辑关系增多
- 干扰项明显加强（与正确选项更接近）
- 文章地道表达明显增多

## 第二部分：四步解题法

| 步骤 | 名称 | 操作 | 时间 |
|------|------|------|------|
| **第一步** | 读 — 速浏览，定主旨 | 快速扫读首段、每段首句、尾段。确定话题和大致内容。 | 1 min |
| **第二步** | 析 — 析选项，提核心 | 读选项。圈出逻辑标志词、代词、核心话题词。判断每个选项的可能位置（段首/段中/段尾）。在旁边做简要标注。 | 2 min |
| **第三步** | 寻 — 看位置，定答案 | **先做段首段尾**（最容易——通常有主旨句或总结句特征）。**再做段中**（过渡句或解释句）。找依据：周围句子的时态、词汇复现、代词指代、逻辑关系、平行句式。 | 5 min |
| **第四步** | 代 — 代所选，看通顺 | 全部填完后，把选项代入原文通读一遍。检查是否连贯自然。不顺的地方调整。 | 1 min |

## 第三部分：八类逻辑关系

七选五的"隐形线索"就是句子之间的逻辑关系。

### 1. 并列关系

**标志词**：and, or, also, as well as, as well, together with, along with, firstly, secondly

**特征**：前后意义同方向，句式结构可能平行。

**解题**：如果空格前后的内容在语义上同向，且没有转折标志，考虑并列关系。

### 2. 递进关系

**标志词**：moreover, furthermore, plus, besides, additionally, in addition, what's more, not only...but (also)..., even worse, worse still, to make matters worse, more importantly, actually

**特征**：后句是前句的进一步深化或补充。

**解题**：如果空格后的内容比前面"更进一步"，且出现了上述标志词，空格应指向更基础的那层意思。

### 3. 顺承关系

**标志词**：then, afterwards, following that, finally, eventually, ultimately, meanwhile, after, from then on, later, after a while, not...until

**特征**：按时间顺序或逻辑顺序自然承接。

**解题**：注意时间线推进——空格前后的动作应该有先后顺序。

### 4. 因果关系

**标志词**：
- 原因：since, now that, because, for, on account of, because of, as a consequence/result of, result from, arise from
- 结果：as a result/consequence, therefore, thus, consequently, so, that's why, set off, give rise to, contribute to, lead to, result in, be responsible for

**特征**：前因后果或前果后因。

**解题**：判断空白处是"原因"还是"结果"，再匹配选项。

### 5. 解释关系

**标志词**：to be specific, specifically, clearly, namely, that is to say, that is, that means

**特征**：后句用更具体的语言解释前句的概括性内容。

**解题**：如果空格前是一个概括性陈述，空格是具体解释 → 用此关系。

### 6. 举例与论证关系

**标志词**：for example/instance, like, range from...to..., such as, take...for example

**特征**：后句提供例子来证明前句的观点。

**解题**：例子往回找主题句——如果空格前是一个观点，空格是例子，则例子应该在语义上支持这个观点。

### 7. 转折/对比/让步关系

**标志词**：
- 转折：however, though, yet, still, otherwise, nevertheless, not...but, (un)fortunately, thankfully
- 对比：instead (of), rather than, on the contrary, in/by contrast, in comparison with, compared with
- 让步：in spite of/despite + n., even if/though, though/although/while, whether...or..., whatever/whoever/no matter what/who + 从句

**特征**：前后意义反向。

**解题**：转折词是七选五最重要的信号之一。如果空格前后内容方向相反，空格必然包含转折意味。

### 8. 总结与概括

**特征**：
- 段首：主题句——概括整段内容
- 段尾：总结句——归纳前文

**解题**：
- 段首空：读整段内容，提取中心词，用中心词匹配选项
- 段尾空：串联前文要点，选能概括的选项

## 第四部分：五大解题技巧

### 技巧1：词汇衔接

这是七选五**最重要**的线索。正确选项的关键词一定会与前后句的关键词形成呼应。

| 复现类型 | 形式 | 示例 |
|----------|------|------|
| **原词复现** | 同一个词出现 | 前句有"memory"，选项中也有"memory" |
| **近义词复现** | 同义词/近义词 | 前句的"important"→ 选项中的"significant" |
| **同源词复现** | 同词根转换 | "character"→"characteristic" |
| **反义词复现** | 反义对比 | "success"→"failure" |
| **同范畴词汇** | 同一语义场的词共现 | 与"旅行"相关：ticket, suitcase, hotel, flight |

**操作**：圈出空格前后两句的关键词 → 在选项中找这些关键词的复现形式。

### 技巧2：代词指代法

| 两大原则 | 说明 |
|----------|------|
| **一致原则** | 同一段落保持叙述人称一致——人指人、物指物、单数指单数 |
| **就近原则** | 遇到代词，向前找最近的可匹配内容 |

| 代词 | 通常指代 |
|------|----------|
| it | 前文的单数/不可数名词 |
| they | 前文的复数名词 |
| this | 前文的动作/方法（多为动词性内容） |
| that | 前文的物/事（多为名词性内容） |
| one/ones | 同类的泛指 |
| those | 特指的复数名词 |

**操作**：如果选项中有代词（it, they, this, that, these, those），向前找它的指代对象。指代对象必须在空格前的句子中出现。

### 技巧3：相似句式法

| 空白位置 | 判断方法 |
|----------|----------|
| **段首** | 观察其他段首句的形式。如果都是祈使句 → 选项也应是祈使句。如果都是问句 → 选项也应是问句。 |
| **段中** | 看选项的句式：问句 → 后文找答句；祈使句 → 表示建议/指令；否定句 → 注意前后肯定/否定的一致性。 |

**操作**：检查空格前后句子的时态（过去/现在）和情态动词使用，确保选项与之一致。

### 技巧4：褒贬一致

**核心原则**：正面配正面，负面配负面。如果正负之间没有转折词，情感不能突变。

**操作**：
1. 判断空格前后句子的情感色彩（正面/负面/中性）
2. 选项的情感色彩必须与前后一致
3. 如果前后情感相反 → 中间必有转折词

**关注词性**：形容词、副词、名词、动词都可以传达情感色彩。

### 技巧5：标点符号法

| 标点 | 含义 |
|------|------|
| **逗号（,）** | 如果空格前后没有连词 → 填从句或介词短语。如果有连词 → 选项不应再带连词。 |
| **问号（?）** | 看到问号想答句。一问一答不分家。 |

**操作**：标点是小技巧，但往往能快速排除明显不匹配的选项。通常与技巧3（相似句式）配合使用。

## 第五部分：技能综合运用

### 5.1 一道题的完整解题流程

以段中空为例：

```
第1层判断：这个空在段首、段中还是段尾？
   → 段中

第2层判断：空格前后的逻辑关系是什么？
   → 看前后句之间有没有逻辑标志词
   → 如果没有显性标志，判断隐含的关系

第3层判断：有没有词汇复现？
   → 圈出空格前后句的关键词
   → 在剩余选项中找这些词的复现形式

第4层判断：有没有代词线索？
   → 如果选项中有代词，向前找指代对象

第5层判断：情感色彩一致吗？
   → 判断空格前后是正面还是负面

综合以上线索 → 选出最佳选项
```

### 5.2 常用排除法

| 排除依据 | 说明 |
|----------|------|
| 代词无指代 | 选项有代词但前文没有对应指代对象 → 排除 |
| 情感冲突 | 空格前后都是正面情感，选项是负面且无转折词 → 排除 |
| 话题不一致 | 选项的话题词与段落主题完全无关 → 排除 |
| 逻辑关系不对 | 空格前后是因果关系，选项是转折关系 → 排除 |
| 句式不平行 | 其他段首句都是祈使句，选项是陈述句 → 排除 |

## 第六部分：教学应用

### 6.1 七选五导问流程

**第一层：文体与语篇结构**
- 这篇文章是什么文体？（说明文 / 记叙文）
- 有没有小标题？（有标题更容易）
- 首段和尾段在说什么？（全文主旨）

**第二层：段落关系与空白位置**
- 这个空在什么位置？（段首 / 段中 / 段尾）
- 段首 → 这段在说什么？（读完整段，提取中心词）
- 段中 → 前后句是什么逻辑关系？
- 段尾 → 前面在说什么？作者想总结什么？

**第三层：选项匹配与验证**
- 选项中有代词吗？它的指代对象在空格前出现了吗？
- 选项的关键词与前后句的关键词有复现吗？
- 选项与前后句的情感色彩一致吗？
- 代入后通读一遍——通顺吗？

### 6.2 学生常见错误

| 错误 | 表现 | 对策 |
|------|------|------|
| **只看空格的上一句** | 忽略跨句的逻辑关系和词汇复现 | 强制要求：看前2句和后2句 |
| **凭感觉"读起来通顺"挑选项** | 没有找具体依据 | 每道题必须说出至少一个具体依据（代词/词汇复现/逻辑关系） |
| **忽略代词** | 选项中有 this/that/it 但没检查指代 | 培养"敏感度"：看到代词就向前找 |
| **先做段中空** | 从最难的地方开始，浪费时间 | 先做段首段尾，再做段中 |

### 6.3 课堂训练模板

```
七选五训练卡（10分钟）

Step 1（1 min）：速读 + 判断文体 + 确定主旨
Step 2（2 min）：读选项 → 标注（代词圈红 / 逻辑词圈蓝 / 话题词下划线）
Step 3（5 min）：逐空分析
  - 空白位置：段首 / 段中 / 段尾
  - 依据1（词汇复现）：________
  - 依据2（逻辑关系）：________
  - 依据3（代词/情感/句式）：________
  - 我的答案：_____
Step 4（2 min）：代入全文通读验证
```
