# Seeklume 语法填空讲评：试用老师快速上手手册

> 版本：2026-05-29
> 对象：提前试用的 1-2 位高中英语老师
> 目标：不用完整学习系统，先用 15 分钟判断它对备课和讲卷是否真的有帮助。

## 1. 先看这一页就够了

Seeklume 现在只做一件事：帮助老师讲语法填空。它不是学生刷题 App，也不是替老师自动备课的工具，而是一个“讲卷工作台”。

这次试用请重点看 4 件事：

| 你要判断什么 | 试用时看哪里 |
|---|---|
| 打开一道题后，讲题台是否适合课堂使用 | 点任意空格，看“做题思路 / 考点 / 迁移训练” |
| 上传 Word 是否顺手 | 在“备课资料”上传一份语法填空或整套卷 |
| AI 解析是否能节省一点备课时间 | 看题号、答案、解析和题量是否基本正确 |
| 迁移训练是否真的像同类题 | 点“迁移训练”，看推荐题是否有讲解价值 |

不用为了试用把所有功能都看完。只要完成下面 15 分钟路线即可。

## 2. 15 分钟试用路线

### 第 1 步：打开网站并进入语法填空

网址：

```text
https://seeklume.work/
```

进入后登录或注册，再选择“语法填空”模块。如果暂时不想注册，也可以先看部分公开题库；但上传 Word、保存资料和跨设备同步需要登录。

### 第 2 步：先用内置真题试讲一道题

1. 进入“按套卷”。
2. 随便选一套试卷。
3. 点击文中的一个空格。
4. 页面会自动打开讲题台并进入全屏讲题状态。
5. 先看“做题思路”，再切到“迁移训练”。

请重点感受：如果这就是课堂投影画面，你会不会愿意用它讲 1-2 道题？

### 第 3 步：上传一份自己的 Word 卷子

建议入口：先用“备课资料”上传。

上传后系统会自动解析语法填空部分。解析完成后：

1. 整篇文章默认进入“备课资料”。
2. 你可以勾选其中几道重点题，让它们额外进入“错题本”。
3. 点击“确认导入”。
4. 再打开这份备课资料，像内置真题一样点空格讲题。

Word 最好包含：

- 语法填空原文
- 题号，如 56-65 或 36-45
- 空格标记，如 `____56____`
- 括号提示词，如 `(make)`、`(possible)`
- 如果有官方答案和解析，请尽量保留“【答案】”“【解析】”

如果上传的是整套卷，系统会尽量只抽取“语法填空”部分，排除阅读、完形和写作。

## 3. 课堂讲题时主要看什么

### 做题思路

先看学生这道题应该怎么判断，而不是先背语法名词。比如：

- 这里是不是缺谓语？
- 主语和动词是什么关系？
- 空格位置需要名词、形容词还是副词？
- 这个从句缺不缺成分？

### 考点

用来确认这道题在知识体系里归到哪里。适合备课时看，不一定要课堂上完整展开。

### 迁移训练

这是本工具最想验证的部分。它会尽量找同类判断路径的题，帮助老师顺手追问：

- 这题和另一张卷子的题为什么算同类？
- 学生错的是形式，还是判断路径？
- 下次换一篇文章，命题人还可能怎么考？

如果你觉得推荐题“不像”，请把试卷名和题号反馈给我。这类反馈最有价值。

## 4. 这次试用请重点反馈

请不要泛泛评价“好不好用”。更希望你帮忙判断下面这些具体问题：

1. 你是否愿意下次备课时再打开一次？
2. 上传 Word 是否顺手？是否有明显等待、卡住或识别失败？
3. AI 解析的题号、答案、解析是否基本靠谱？
4. 讲题台是否适合投影给学生看？
5. 迁移训练推荐出来的题，是否真的能放在一起讲？
6. 哪一个地方最让你困惑、最想让我先改？

## 5. 隐私和边界提醒

- 当前版本只做“语法填空讲评”，完形、阅读、写作以后再扩展。
- AI 解析可能出错，正式上课前请人工扫一遍答案和关键解析。
- 请不要上传包含学生姓名、班级名单、成绩、身份证号、家长联系方式等隐私信息的文件。
- 如果只是试用，建议先上传一份不含学生个人信息的公开卷或已脱敏材料。
