# 第2讲 用虚拟条件句表"假设"

## 概述
本讲详细讲解虚拟条件句的用法，包括与现在、将来、过去事实相反的三种情况，错综时间虚拟条件句，if的省略倒装结构，以及was与were的使用区别。虚拟条件句用于表示与事实相反的假设，是虚拟语气的核心内容。

## 详细内容

### 考点1. 真实条件句与虚拟条件句

**真实条件句**: 假设的情况有可能发生，谓语用陈述语气。
- If it doesn't rain tomorrow, we will go to the park. (如果明天不下雨，我们就去公园。)

**虚拟条件句**: 假设的情况过去或现在都不存在，或将来不大可能发生。
- If he had seen you yesterday, he would have asked you about it. (如果他昨天见到你，他会问你这件事的。事实上他昨天没见到你，因此也未能问你这件事。)

### 考点2. 虚拟条件句的三种基本情况

| 时间 | if条件句的谓语形式 | 主句的谓语形式 |
|------|-------------------|----------------|
| 现在 | did(were) | would/should/could/might do |
| 将来 | ①should do (should不能省略)<br>②were to do<br>③did(were) | would/should/could/might do |
| 过去 | had done | would/should/could/might have done |

**示例**:
- **与现在相反**: If I knew German, I would read the book in the original. (如果我懂德语，我就读这本书的原著。)
- **与将来相反**: If it should snow/were to snow/snowed tomorrow, I would stay at home. (如果明天下雪，我就待在家里。)
- **与过去相反**: If you had put on more clothes, you wouldn't have caught a cold. (如果你多穿些衣服，你就不至于感冒了。)

### 考点3. 主句中would、should、could、might的选择

- **would**: 一般常用，如同真实条件句中主句常用will一样，常译作"将；就会"
  - If I knew him, I would ask him for help. (如果我认识他的话，我就会向他求助。)
- **could**: 有"能够，可能"之意
  - If you had come back a little earlier, you could have seen it yourself. (如果你稍早一点回来，你就可能目睹这件事了。)
- **might**: 常译作"或许"，表示可能有，但不敢肯定
  - If I had been there, I might have quarreled with him. (如果我当时在场的话，我或许会和他吵起来。)
- **should**: 在虚拟条件句的主句中用得较少(主要用于主语是第一人称时，但常被would代替)

### 考点4. should有"万一"之意

在与将来相反的虚拟条件句中，从句谓语有三种形式，其中一种为"should + 动词原形"，主要因为should有"万一"之意，表示一件事听起来可能性很小，但也不是完全没有可能。此时，should不能省略。

if条件从句谓语由should加动词原形构成时，主句谓语有用虚拟语气的也有不用虚拟语气的。

**示例**:
- Ask her to ring me up if you should see her. (你万一见到她，请让她给我打个电话。)

should还常用在for fear that, in case (以防), lest (以防)等引导的状语从句中。

### 考点5. 错综时间虚拟条件句

即条件从句与主句所指时间不一致，如从句指过去，而主句却指的是现在或将来，此时应根据具体的语境情况，结合三种基本类型对时态作相应的调整。

**示例**:
- If they had started in the early morning, they would arrive in half an hour. (过去→将来；错综时间虚拟条件句)
- If they had started in the early morning, they would be here now. (过去→现在；错综时间虚拟条件句)
- If they had started in the early morning, they would have arrived. (过去→过去；不是错综时间虚拟条件句)

### 考点6. if的省略（倒装结构）

虚拟条件句中有were、had、should时，可把if省略，而把were、had、should放在主语前，用倒装结构，这种结构主要用于书面语中。

**示例**:
- Were it necessary, I might resign.
- Should it rain tomorrow, we would have to put off the visit to the Summer Palace.
- Were there to be a flood, what should we do?
- Had I left a little earlier, I would have caught the train.

### 考点7. 用was还是用were

在虚拟语气中，一般要用were。但在当代英语中，尤其在口语中，单数主语常用was代替虚拟式were。

**示例**:
- I wish I was ten years younger. (我但愿年轻10岁。)

在含义上，有时was发生的可能性大于were。

**示例**:
- He looks as if he was ill. (他像是病了。)

**但在倒装虚拟结构及if I were you中，只能用were**:
- Were I ten years younger, I would study abroad. (要是我还年轻10岁的话，我会去国外学习。)
- If I were you, I would try my best to grasp the chance. (要是我是你的话，我要尽力抓住这次机会。)

在正式文体中仍须用were。在考试中最好还是用were。

### 考点8. 根据主句谓语或从句谓语判断是否是虚拟语气

一般情况下，从句和主句要用陈述语气都用陈述语气，要用虚拟语气都用虚拟语气。

**示例**:
- Would you mind if I opened the window? (虚拟语气)
- 比较: Do you mind if I smoke? (陈述语气)

我们可以利用这个规律来帮助我们做题。

**注意**: should用在条件从句中表示"万一"时，主句可用陈述语气也可用虚拟语气。
- If he should come tomorrow, I will/would ask him for help.

### 考点 9. 零条件句、第一条件句、第二条件句和第三条件句

英语中的条件句分为真实条件句和非真实条件句，非真实条件句也叫虚拟条件句。

- **零条件句**: 表示只要满足了某个条件，总会出现某种现象或导致某种结果，常用于表示经过验证的科学理论等，也用于表达一种总会发生的客观事实。
  - If you heat water to 100 degrees, it boils.

- **第一条件句**: 用于表示未来可能会发生或成为现实的条件或假设，遵循主将从现的原则。
  - If it rains tomorrow, we'll have to put off the sports meeting.

- **第二条件句**: 用于表示现在事实相反或将来不可能成为现实的条件或假设。
  - If I had ten million dollars, I would buy that villa.

- **第三条件句**: 用于表示与过去事实相反的条件或假设。
  - If I had followed his advice, my girlfriend wouldn't have left me.

**分类总结**:
- 零条件句和第一条件句属于真实条件句
- 第二条件句和第三条件句属于非真实条件句，即虚拟条件句

## 核心要点总结

1. **三种基本虚拟条件句**:
   - 现在相反: did/were → would do
   - 将来相反: should do/were to do/did → would do
   - 过去相反: had done → would have done

2. **情态动词选择**:
   - would: 一般情况
   - could: 表示可能、能够
   - might: 表示或许、不确定
   - should: 少用，主要用于第一人称

3. **特殊结构**:
   - should表"万一": 用于将来条件句，可能性小但存在
   - 错综时间: 主从句时态不一致，需根据语境调整
   - if省略倒装: were/had/should提至句首

4. **was/were使用**:
   - 一般用were
   - 口语中单数主语可用was
   - 倒装结构和if I were you中必须用were

5. **条件句分类**:
   - 真实条件句: 零条件句、第一条件句
   - 虚拟条件句: 第二条件句、第三条件句
