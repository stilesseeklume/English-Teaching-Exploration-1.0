## 第一部分 · 先把你教会（技法原理）

### 1.1 这套笔记在解决什么问题

口译员一边听一边记，记完立刻要把整段话讲出来。他不可能把话抄下来——来不及，也没用。他做的是：**把一整段话压缩成少量视觉符号**，而这些符号的唯一功能是**把人带回原话**。

关键认知一句话：

> **笔记不是记录，是线索（retrieval cue）。**

学生背课文卡住，也是同一个病：课文太长，脑子里没有抓手。笔记法就是给课文造抓手。

要让学生记住的一句话：

> **笔记越少越好。写得多，说明你记的是词，不是意。**

### 1.2 三条铁律

| # | 铁律 | 反面（学生常犯） |
|---|------|----------------|
| 1 | **竖排，一行一个意群**，眼睛只往前，不回扫 | 横着抄句子 |
| 2 | **缩进表示从属**，谁是谁的下级用缩进 + 树形符号，不用连接词 | 用「然后」「所以」把内容串成一句 |
| 3 | **专名缩写、逻辑用符号**：Lang Ping → `LP`，因为 → `∵` | 把 because、so 一字不差写下来 |

### 1.3 符号表（就是我们 U3 数据里已经用到的那些）

| 符号 | 含义 | 例子 |
|------|------|------|
| `●` | 主题 / 顶格（一段的顶） | `● LP 郎平` |
| `├ └` | 分支 / 末分支 | 挂在 `●` 下面 |
| `→` | 导致、指向、结果是 | `as player → honour` |
| `∵` `∴` | 因为 / 所以 | `captain 走 ∵ heart`、`∴ 2wk → 世界冠军` |
| `↑` `↓` | 增加、上升（伤、多） / 减少、损失 | `↑injured`、`2 ↓` |
| `≠` | 不等于、不是 | `accept 败 ≠ accept 不 try` |
| `=` `↳` | 是、即 / 换句话说 | `mental strength = unique` |
| `：` | 展开、解释 | `2015 WCup：best player ↑injured` |
| `+` `!` | 并列 / 强调 | `honour + glory`、`世界冠军 !` |
| `@` | 在（地点或时间） | `@Chicago 1996` |
| `/` | 一段结束 | 行末用 |

**缩写规则**：专有名词取首字母（`LP`=Lang Ping、`MJ`=Jordan）；常见数量词去元音（`wk`=week、`mth`=month）；只在「第一次出现」时可稍写全，之后一律用缩写。

### 1.4 一条自检判据（你检查学生笔记的唯一标准）

> **遮住原文，只看笔记，能不能把原话说回来？**

- 能 → 合格。
- 不能 → 要么意群切错了，要么缩进乱了，要么记的是词不是意。

这条判据学生自己就能用，比他写完你看一眼有效得多。

## 第二部分 · U2 RT《Travel Peru》示范（学生已背过 → 适应期）

### 2.1 为什么先拿 U2

学生**已经背过**这篇，所以：

- 不用分心去理解内容，**全部注意力放在「怎么记」上**；
- 记完立刻可以拿自己的记忆做验证——「我照着笔记，能不能把背过的原话调出来」，学得快。

U2 的文体是**旅游手册**：开篇一段百科背景，中间四条线路**并列**，结尾一句号召。**并列结构 = 最简单的骨架**，适合第一课。

### 2.2 全文骨架（先立骨架，再看细节）

```
● Travel Peru（旅游手册）
├ ① 概况 · Peru
├ ② Amazon 雨林
├ ③ Machu Picchu
├ ④ Cusco
├ ⑤ Lake Titicaca
└ ⑥ 号召 · Come to Peru
```

### 2.3 逐块笔记 + 原文锚句

> 每一块给两栏：**左 = 口译笔记**（学生要会自己写出来的），**右 = 原文锚句**（背原文时挂上去的那一句）。

**① 概况 · Peru**

```
● Peru 概况
├ 位置：Pacific coast @S.America
├ 3 区：coast（窄·干·平）+ Andes + Amazon
├ 1400-1500s → Inca 帝国中心
│ └ Machu Picchu ← emperor 住
├ 16c Spain 控 → 1821
└ ∴ 官方语 = Spanish
```

锚句：`Peru is a country on the Pacific coast of South America with three main areas...`
锚句：`It is for this reason that Spanish is the main official language of Peru.`

**② Amazon Rainforest Tour**

```
● Amazon 雨林 · 4 天
├ ✈ 短途飞行：Cusco → Andes → Amazon
├ 🚤 1d 船 → 林中 accommodation
└ 3d：guide + 探索 plants/animals（unique）
```

锚句：`A short flight from Cusco takes you from the Andes into the Amazon rainforest.`

**③ Machu Picchu Tour**

```
● Machu Picchu · 4d 徒步
├ 徒步 → Andes paths → 古城
├ 到达后 1d：explore + amazed
└ 尤其 amazing = Inca dry stone
   └ 切石 exact size → 墙靠 perfect fit（≠ 黏合）
```

锚句：`Especially amazing is the Incas' dry stone method of building.`
锚句：`Inca builders cut stones to exact sizes so that nothing was needed to hold walls together other than the perfect fit of the stones.`

**④ Cusco Tour**

```
● Cusco · 4d
├ 高地 Andes · Spanish + Indian 文化
├ = Inca 首都（13-16c）
└ 活动：hotel + museum + architecture + food + market
```

锚句：`Spend four days enjoying the unique Spanish and local Indian culture high in the Andes at Cusco...`

**⑤ Lake Titicaca Tour**

```
● Titicaca · 3d 住岛
├ 🚗 1d 新公路：Cusco → Titicaca（乡村风光）
├ 🚤 → island + Uros family
└ 岛 & 房 = 湖中 water plants
```

锚句：`Both the island and the Uros homes are made of water plants from the lake.`

**⑥ 号召 · Come to Peru**

```
● 号召 · Come to Peru
└ 体验：Inca 文化 + Spanish 村庄 + 雨林 + 高山 + 海岸
```

锚句：`So come and experience what Peru has to offer: everything from ... to ...`

### 2.4 关键发现：四条线路共用一副模具

把中间四块横着比一比，会发现它们其实是**同一副模具**：

| 线路 | 去哪 | 怎么去 | 待几天 | 干什么 |
|------|------|--------|--------|--------|
| Amazon | 雨林 | ✈ + 🚤 1d | 3d | 探索动植物 |
| Machu Picchu | 古城 | 徒步 | 4d | 探索古城 + 惊叹干砌石 |
| Cusco | 库斯科 | — | 4d | 博物馆 / 建筑 / 美食 / 市场 |
| Titicaca | 的的喀喀湖 | 🚗 1d | 3d | 与 Uros 家庭住岛 |

**要教给学生的就这一句**：手册类文章，四条线路共用一副模具——**去哪 → 怎么去 → 待几天 → 干什么**。抓住模具，四段就是一段，背起来量就小了一半。

### 2.5 课堂动作（适应期）

1. 你先把 ①②③ 的笔记示范在黑板上（**边写边讲为什么这么缩进、为什么用这个符号**）。
2. 然后**放手让全班一起做 ④⑤**——合上书，凭记忆和模板写。
3. 收上来，只用 1.4 的判据检查：**遮住原文，能不能说回来**。
4. 最后亮出 2.4 那张表，让学生自己发现「四段是同一副模具」。

## 第三部分 · U3 RT《Living Legends》迁移

### 3.1 结构升级：从「并列」到「嵌套」

U2 是并列的五块，U3 不一样——它是**征稿 + 两个例证**，例证内部各有自己的小线：

- 郎平那段：「三个身份 → 一次考验 → 结果」
- 乔丹那段：「球技 → 精神 → 回馈」

**这是嵌套骨架，比 U2 难一级，正好接着练。**

### 3.2 全文骨架

```
● Living Legends（征稿）
├ ① 开篇：选谁？标准 = masters + good examples
├ ② 郎平：3 身份 → 考验 → 夺冠
├ ③ 乔丹：球技 → 精神 → 回馈
└ ④ 号召：投稿
```

### 3.3 逐段笔记（沿用数据里已有的成品，这里只给教学口径）

**① 开篇 · 两条标准**

```
● Living Legends
├ 选谁 → masters + good examples
└ 先出 first 2 choices
```

**② 郎平 · 团队逆境**（数据里已有 7 行，见 `textbook_reading_notes.js` 的 `sections[1].notes`）

```
● LP 郎平
├ as player → honour + glory → 国
├ as coach → 中女排 → medals 世锦赛/奥运
├ as person → fans 爱 home + abroad
├ 2015 WCup：best player ↑injured + captain 走 ∵ heart
├ 2 ↓ ≠ lose heart → faced 难 before
└ ∴ 2wk → 世界冠军 ! / 2016 → 奥运金 @巴西
```

**③ 乔丹 · 个人精神**

```
● MJ 乔丹
├ "Air Jordan"：graceful moves + jumps → 改篮球
├ skills impressive ↳ mental strength = unique
├ final sec → 总 find a way to win
├ secret = learn ∵ failures：accept 败 ≠ accept 不 try
├ 败 → practise harder + never give up
└ 回馈：share success + Boys&Girls Club @Chicago 1996
```

**④ 号召 · 投稿**

```
● 投稿 → LLS@sports.net
```

### 3.4 课堂动作（迁移期）

和 U2 反过来：**这次不给示范，学生自己记**。

1. 只给全文骨架（3.2）和符号表，让学生**自己写每一段的笔记**。
2. 同桌互查：**遮住原文，看对方笔记能不能说回来**。
3. 全班对齐——你会发现「同一个意群，不同学生切法不同」，**这个差异本身就是最好的教学素材**。
4. 最后把成品笔记（3.3）亮出来，作为标准答案对照。

> 迁移期的重点是让学生体会：**U2 的并列模具在 U3 拆成了嵌套**，但三条铁律没变。

## 第四部分 · 学生用的框架模板（双栏）

学生手上拿的应该是一张这样的一屏框架，一段课文填一块：

```
┌──────────────────────────────┬──────────────────────────────────┐
│ 段名 · 骨架                   │                                  │
│ （顶格写 ●，下面接 ├ └）       │                                  │
├──────────────────────────────┼──────────────────────────────────┤
│ 口译笔记（自己填）             │ 原文锚句（背点）                  │
│ ● …                          │ …                                │
│ ├ …（→ ∵ ∴ ≠ ↑ ↓）           │ …                                │
│ └ …                          │ …                                │
└──────────────────────────────┴──────────────────────────────────┘
```

用法：**先默写左栏，再对照右栏把整句补齐。** 这一步就是从「记意」到「背原文」的桥。
