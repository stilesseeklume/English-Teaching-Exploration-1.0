## 口径

- 功能轴：作主语/表语、作宾语、作定语、作状语、作补语、with 复合结构。
- 形式轴：to do、doing、done、to be done、being done、having done 等。
- 课堂判断顺序：先看句中是否已有谓语，再找逻辑主语判断主被动，最后确定形式和功能。
