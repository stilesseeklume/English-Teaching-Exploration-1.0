# Seeklume 课堂判断层升级方案

> 目标：把现有“教材 / 教辅知识目录层”升级为老师讲题真正需要的“课堂判断层”。
> 状态：第一版方案。非谓语已作为试点，见 `docs/planning/nonpredicate-audit.md`。
> 2026-05-27 进展：解析页和迁移训练页已接入课堂判断层，优先展示讲题抓手与同类判断路径；知识路径保留为折叠信息。

---

## 1. 核心判断

现有知识层并不是错，而是用途偏“归档知识”：

- 教材视图回答：这个语法点在哪本书、哪个单元出现？
- 语法通霸视图回答：这个语法点在完整体系里属于哪一章？
- fine tag 回答：这道题挂在哪个知识节点下？

但老师课堂讲题更常问另一组问题：

- 学生第一步该看什么？
- 这题最容易错在哪里？
- 这题和另一题为什么算同类？
- 讲这题时用什么判断路径最省力？

因此，Seeklume 后续不应推翻现有知识层，而是在其上增加一层：

**课堂判断层（teaching axes）**。

---

## 2. 当前全类目扫描结论

基于当前公开题库 19 套约 190 题，第一轮扫描发现以下错位。

| 类别 | 当前题量 | 当前主要 tag | 课堂讲题错位 | 升级优先级 |
|---|---:|---|---|---|
| 词性转换 word | 57 | 形容词/副词选用、名词派生、复数 | 老师更需要“空格缺什么句子成分 + 变什么词性” | P0 |
| 非谓语 nonpredicate | 37 | 作宾语/定语/状语/补语 | 老师更需要 `to do / doing / done` 与功能双轴 | P0 |
| 谓语 predicate | 26 | 时态/语态/主谓一致 | 真实题常同时考时态、语态、一致，单 tag 不够 | P0 |
| 介词 preposition | 17 | common / verb | “常见介词”太泛，需区分关系与搭配来源 | P1 |
| 冠词 article | 14 | the / a-an | 需区分泛指、特指、固定搭配、最高级等触发点 | P1 |
| 定语从句 attrib | 14 | 关系词选择/关系副词/限制非限制 | 需按“先行词 + 从句缺成分 + 关系词功能”讲 | P1 |
| 逻辑连词 logic | 12 | 并列连词 | `and/or/but/so` 的课堂讲法完全不同 | P1 |
| 代词 pronoun | 7 | 人称/物主/反身/it | 需找指代对象、句中功能、数/格/反身关系 | P2 |
| 名词性从句 nounclause | 6 | wh words | 需区分从句角色与连接词是否作成分 | P2 |

额外发现：

- 当前有一些 `category` 与 `fine_category` 所属类不完全一致，例如 `word` 题里挂了 `num-plural`。这类不一定影响显示，但会影响迁移训练的“同类题”可信度。
- 冠词里存在若干答案是 `a/an` 但 fine tag 是 `art-the` 的题，需要先做一次快速校准。
- 个别从句题边界需要复核，例如 `when` 既可能是定语从句关系副词，也可能是时间状语从句连词。

## 3. 新增字段建议

每道题保留现有字段：

```js
category: "nonpredicate",
fine_category: "nonp-attribute"
```

新增课堂判断层：

```js
teaching_axes: {
  decision_path: "先判已有谓语 -> 找逻辑主语 -> 判主被动 -> 定形式",
  form: "done",
  function: "作定语",
  trigger: "被修饰名词与动词构成动宾关系",
  common_mistake: "误填 doing 或误判为谓语被动",
  migration_keys: ["nonpredicate:done:attribute", "nonpredicate:passive-complete"],
  review_status: "reviewed"
}
```

字段说明：

| 字段 | 作用 |
|---|---|
| `decision_path` | 老师讲题的判断顺序 |
| `form` | 表面形式或答案类型，如 `to_do`、`done`、`the`、`plural` |
| `function` | 句中功能，如作定语、修饰动词、引导宾语从句 |
| `trigger` | 触发答案的关键线索 |
| `common_mistake` | 学生常错方向 |
| `migration_keys` | 迁移训练优先匹配键 |
| `review_status` | `ai_generated` / `reviewed` / `needs_review` |

## 4. 各类课堂判断轴

### 4.1 非谓语动词（P0）

从单轴升级为双轴：

| 轴 | 示例 |
|---|---|
| 形式轴 | `to_do`、`doing`、`done`、`to_be_done`、`being_done`、`having_done` |
| 功能轴 | 作宾语、作定语、作状语、作补语、作主语/表语、with 复合结构 |
| 关系轴 | 逻辑主谓、逻辑动宾、目的/将来、同时/伴随、完成/状态 |

迁移训练优先级：

1. 同形式 + 同功能
2. 同形式
3. 同功能
4. 同非谓语粗类

### 4.2 谓语动词（P0）

谓语题不能只归到“时态/语态/主谓一致”之一，建议多轴：

| 轴 | 示例 |
|---|---|
| 有限动词判断 | 句中是否缺谓语 |
| 时间线索 | `since`、`in 2023`、`always`、上下文过去叙事 |
| 语态关系 | 主语执行动作 / 主语承受动作 |
| 主谓一致触发 | 主语中心词、动名词短语作主语、there be、就近一致 |
| 最终形式 | `does`、`did`、`is done`、`has been doing` |

迁移训练优先级：

1. 同时间线索 + 同最终形式
2. 同语态关系
3. 同主谓一致触发
4. 同谓语粗类

### 4.3 词性转换（P0）

当前“形容词/副词选用”过粗。课堂上应按“空格位置”讲：

| 轴 | 示例 |
|---|---|
| 目标词性 | 名词、形容词、副词、比较级、复数 |
| 句中位置 | 修饰名词、修饰动词/形容词/整句、作表语、作宾语 |
| 触发线索 | 冠词后、形容词后、系动词后、名词前、动词后 |
| 词形变化 | `-ly`、`-tion`、`-ment`、`-ness`、复数、比较级 |

迁移训练优先级：

1. 同目标词性 + 同句中位置
2. 同词形变化
3. 同词性转换粗类

### 4.4 冠词（P1）

冠词应从“a/an/the 章节”转向“指称判断”：

| 轴 | 示例 |
|---|---|
| 答案形式 | `a`、`an`、`the`、零冠词 |
| 指称类型 | 泛指、特指、独一无二、类指 |
| 名词属性 | 可数单数、不可数、复数 |
| 固定触发 | 最高级、序数词、乐器、固定短语 |

必须先校准：所有答案为 `a/an` 却挂 `art-the` 的题。

### 4.5 介词（P1）

介词不能长期停留在 `prep-common`：

| 轴 | 示例 |
|---|---|
| 关系类型 | 时间、地点、方向、来源、方式、对象、原因 |
| 搭配类型 | 动介搭配、形介搭配、名介搭配、固定短语 |
| 答案形式 | `in`、`on`、`at`、`for`、`to`、`with`、`by`、`from` |

迁移训练优先级：

1. 同答案形式 + 同关系/搭配类型
2. 同关系/搭配类型
3. 同介词粗类

### 4.6 逻辑连词（P1）

逻辑连词应从“并列连词”升级为“逻辑关系”：

| 轴 | 示例 |
|---|---|
| 逻辑关系 | 并列、选择、转折、因果、递进、条件 |
| 结构触发 | `whether...or`、`either...or`、`not only...but`、祈使句 + and/or |
| 答案形式 | `and`、`or`、`but`、`so`、`yet` |

### 4.7 定语从句（P1）

定语从句课堂判断顺序：

1. 找先行词
2. 看从句缺不缺成分
3. 缺主/宾/表 → 关系代词
4. 缺状语 → 关系副词或介词 + which/whom
5. 看逗号判断限制/非限制

建议轴：

| 轴 | 示例 |
|---|---|
| 先行词类型 | 人、物、时间、地点、原因、整句 |
| 从句成分缺口 | 主语、宾语、定语、状语、不缺 |
| 关系词形式 | who、which、that、whose、where、when、why |
| 限制性 | 限制性、非限制性 |

### 4.8 名词性从句（P2）

名词性从句不能只按 wh 词归类：

| 轴 | 示例 |
|---|---|
| 从句角色 | 主语从句、宾语从句、表语从句、同位语从句 |
| 从句缺口 | 缺主语/宾语/表语、不缺成分 |
| 连接词意义 | 什么、为什么、怎样、是否、无意义 that |
| 答案形式 | what、how、why、whether、that |

### 4.9 代词（P2）

代词课堂判断层：

| 轴 | 示例 |
|---|---|
| 指代对象 | 前文名词、句子整体、主语自身 |
| 句中功能 | 主语、宾语、定语、同位/强调 |
| 形式 | 人称、物主、反身、不定、指示、it |
| 数/格 | 单复数、人称、主格/宾格/所有格 |

## 5. 迁移训练新规则

现有迁移训练主要按 `fine_category` 找同类题。升级后改为：

1. 如果题目有 `teaching_axes.migration_keys`，优先用 migration key。
2. 如果没有 migration key，回退到 `fine_category`。
3. 如果没有 fine_category，回退到 `category`。

当前页面实现原则：

- 解析页先显示“课堂判断”，包含判断抓手、步骤、追问和常错点。
- 原有知识路径不删除，但折叠到后面，避免老师讲题时被知识目录牵着走。
- 迁移训练优先按课堂判断路径匹配；非谓语额外保留“同形式 + 同功能 → 同形式”的高优先级。
- 题卡标签尽量显示可讲的判断名，例如“非谓语：done · 作定语”“词性转换：变副词”，而不是只显示教材 tag。

展示文案也应从“考点：非谓语作定语”升级为：

```text
同类判断：done 作定语
判断抓手：被修饰名词与动词构成动宾关系
常见误区：误填 doing 或误判成谓语被动
```

这样老师看到的不是一个目录名，而是一条可以直接讲给学生的判断路径。

## 7. 验收标准

第一阶段不以“字段多”为成功标准，而以老师信任为准：

- 老师随机点 5 道非谓语题，能说“这些题确实是一类”
- 老师能看懂抽屉顶部的判断路径，不需要先懂 tag 名
- 新上传的 10 道非谓语题能进入同一套判断体系
- 错题本里的非谓语题也能和内置题库互相迁移
- 没有明显“答案是 a/an 却说定冠词 the”这类低级错位

## 8. 近期建议

下一个开发动作建议只做一件事：

**把非谓语的 `功能轴 + 形式轴 + migration_keys` 跑通。**

原因：

- 非谓语题量足够，当前有 37 道内置样本
- 老师痛感最强，最容易判断“有用/没用”
- 这套模式验证成功后，可以复制到谓语、词性转换、冠词和从句
- 下周二演示时，这会比继续堆功能更有说服力

## 9. 防止分类膨胀的治理规则

持续优化所有错位时，最大的风险不是“分类不够”，而是“每发现一个新角度就新增一个平级分类”，最终导致老师和开发者都分不清每个标签的用途。

因此后续必须遵守三条边界：

1. **不再把所有东西塞进一个 tag**

   `category` / `fine_category` 只负责知识目录归属，不负责承载全部课堂讲法。

   - `category`：高考语法填空大类，如非谓语、谓语、冠词。
   - `fine_category`：知识目录节点，如非谓语作定语、主谓一致、定冠词。
   - `teaching_axes`：课堂判断路径，如 `done + 作定语 + 动宾关系`。

2. **新增分类前先判断它属于哪一层**

   | 新信息 | 应放位置 | 例子 |
   |---|---|---|
   | 知识体系节点 | `fine_category` | 非谓语作定语、关系副词 |
   | 答案表面形式 | `teaching_axes.form` | to_do、doing、done、the、plural |
   | 句中作用 | `teaching_axes.function` | 作定语、修饰名词、引导宾语从句 |
   | 触发线索 | `teaching_axes.trigger` | decide 后接 to do、从句缺主语 |
   | 学生错因 | `teaching_axes.common_mistake` | doing/done 混淆、a/the 混淆 |
   | 迁移训练匹配键 | `teaching_axes.migration_keys` | nonpredicate:done:attribute |

3. **迁移训练只吃少量稳定键**

   迁移训练不直接展示所有字段，只使用 `migration_keys` 做匹配。字段可以丰富，但老师看到的仍然是清晰的一句话：

   ```text
   同类判断：done 作定语
   判断抓手：被修饰名词与动词构成动宾关系
   ```

### 不做的事

- 不建立几百个平级 fine tag。
- 不让 AI 自由发明 tag 名。
- 不把教材目录、语法通霸目录、课堂判断法混成同一套分类。
- 不要求每一题都填满所有字段；只填对讲题和迁移有用的字段。

### 最终原则

分类不是越细越好，而是**每一层只回答一个问题**：

| 层 | 回答的问题 |
|---|---|
| 粗类 `category` | 这题属于哪一大类？ |
| 知识节点 `fine_category` | 它在语法体系里属于哪一节？ |
| 课堂判断 `teaching_axes` | 老师上课怎么判断、怎么讲？ |
| 迁移键 `migration_keys` | 哪些题真的可以放在一起练？ |

只要保持这四层边界，分类会越来越清楚，而不是越来越混乱。
