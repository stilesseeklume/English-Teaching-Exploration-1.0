怎么开始用

  1. 注册账号：邮箱 + 用户名 + 密码。注册后会有一小段管理员审批的等待，多包涵。
  2. 选一套真题，或者按考点直接练，点空格弹出解析。
  3. 讲过的题加入错题本，下次自动把别的卷子里同考点的题列出来，做迁移训练。
