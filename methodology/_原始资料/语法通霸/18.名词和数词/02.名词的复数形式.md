# 第2讲 名词的复数形式

## 概述

*本讲讲解名词单数变复数的规则及特殊变化情况。重点掌握规则变化（加-s/-es）、不规则变化（如 -ch/-th/-o/-f/-um 结尾等特殊处理）、复合名词的复数形式、名词作定语的用法，以及单复数形式相同的名词和只有复数形式的名词。*

## 考点1. 名词单数变复数的规则

一般规则：大多数名词在词尾加 -s 构成复数。

以 s, x, ch, sh 结尾的名词加 -es；以辅音字母 + y 结尾的名词变 y 为 i 再加 -es；以 o 结尾的名词有的加 -s，有的加 -es；以 f 或 fe 结尾的名词一般变 f/fe 为 v 再加 -es。

## 考点2. 名词单数变复数特殊情况

### A. -ch 结尾的特例

以 -ch 结尾但发 [k] 音时，复数只加 -s：

- stomach → stomachs ['stʌməks] 胃
- sandwich → sandwiches 三明治

### B. -th 前面是长元音时，复数 [θ] 的读音要变为 [ð]

- mouth [maʊθ] → mouths [maʊðz] 嘴巴
- path [pɑːθ] → paths [pɑːðz] 小路
- bath [bɑːθ] → baths [bɑːðz] 洗澡

### C. 以 -o 结尾加 -s 或 -es 都行的词

- zero → zeros/zeroes
- volcano → volcanos/volcanoes

### D. 以 -f 结尾加 -s 变复数的几个出现频率较低的词

- roof → roofs, belief → beliefs, chief → chiefs, proof → proofs, gulf → gulfs

### E. 一些以 -um 结尾的外来词，复数形式变 -um 为 -a

- datum → data, medium → media, bacterium → bacteria

### F. 由其他语言音译表示度量、币制等单位的名词复数不按英语规则，不加 -s

- yuan（元）, jin（斤）, li（里）, mu（亩）

### G. 字母、数字、符号、缩略语等当看作个体名词时在其后加 -s 或 -'s 都行

- in the 1990s/1990's 在20世纪90年代
- two MPs/MP's 两名议员

### H. 复合名词的复数形式要变中心词

- passer-by → passers-by 路人
- son-in-law → sons-in-law 女婿
- looker-on → lookers-on 旁观者

## 考点3. 名词作定语时

名词作定语修饰另一个名词时，通常用单数形式（即使含义是复数意义）：

- a bicycle shop 自行车商店（bicycle 用单数）
- letter boxes 信箱（letter 用单数）

但 man 和 woman 作定语修饰复数名词时，也要变为复数：

- men teachers 男教师们
- women doctors 女医生们

## 考点4. 单复数形式相同、只有复数形式、由两部分组成常以复数出现的名词

### A. 单复数形式相同的名词

- sheep, deer, fish, Chinese, Japanese, means（方式）, series, species, works（工厂）

### B. 只有复数形式的名词

- clothes, trousers, pants, shorts, scissors, glasses（眼镜）, goods, thanks

### C. 由两部分组成常以复数形式出现的名词

- compasses（圆规）, scales（天平）, glasses（眼镜）, trousers（裤子）
